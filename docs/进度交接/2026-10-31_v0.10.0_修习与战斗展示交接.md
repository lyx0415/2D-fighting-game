# v0.10.0 修习与战斗展示交接

2026-10-31。用户本轮五项要求均已接入可游玩代码；完整数值见[版本记录](../版本记录/v0.10.0_修习系统与战斗展示.md)，素材与文件哈希见素材库/catalog.json。此前v0.9源码/文档/清单快照在artifacts/v009-before-v010，旧图像和声音未覆盖。

## 已实现

1. 普攻出手/普通命中增益降至0.15/0.12，较旧0.65减少约77%/82%的信号振幅；普通声部并发上限5，技能保持突出。主音量与HTMLAudio后备统一遵循分类增益。
2. 新50WAV：原39效果+6环境继承ID，其中17技能/命中重制，新增5职业发力。破空、弦/冰/火/盾/刃与较长尾响区分；陨火爆发仅命中时播放。发力来自本机SAPI合成并后处理，非真人喊声。
3. 独立生成石道路面，原生比例截取/铺设；建筑背景收束于路缘外。y360～620矩形可走带不变，物件退到边界外，路缘有厚度、暗缝和灯点，拒绝路外点击。
4. 英雄0.225（再缩小约15%）、普通敌0.21、狼0.19、Boss0.35；相应调阴影、脚圈、护盾与选敌框。
5. 营地英雄成长增加3类天赋（各5点上限）与两个技能Lv1～4。每级1天赋点、每偶数级1技能点；10级共9/5点，免费重置。天赋生命/攻击/护甲，技能效力与CD真实影响下一战。旧v1存档无需迁移或重开，缺失字段默认零分配、预算按等级计算。

## 源码与维护入口

- 规则core/training.ts；成长progression.ts、存档save.ts、技能battle.ts；UI为ui/training.ts、training.css及main.ts。
- 渲染统一art.ts入口；新ground URL在raster-art.ts、背景和路面组合terrain.ts、尺寸和声音事件scene.ts。
- audio-mix.ts分类策略；audio.ts两后端与声部限制；audio-assets.ts当前v010地址。
- 新运行图public/assets/v010（原画v008与姿态v009继续用）；新音public/audio/v010。图像原稿/完整prompt在素材库/08_生成原稿/v010。声音合成原稿和来源清单在v010/source及[音频说明](../音频v010.md)。
- npm run art:ground只进行图像格式打包；npm run audio:build按已保留原稿重建；仅重新合成SAPI原稿才需要本机Huihui/Zira。日常启动不依赖生成工具、外链或语音引擎。

## 实际验证

77规则测试通过，包含19条修习/分类混音测试，覆盖8种攻击技能的投射物/范围/直伤管线、护盾/减伤、CD、预算/上限/重置/坏档备份。既有四随机种子未配点十关模拟通过；这不代表新配点树已完成平衡验收。

双引擎既有40项（含生产）回归通过；最终12项专项通过（合计50个不同浏览器用例），结果见[当前测试报告](../TEST_REPORT.md)。生产已实际新档开战并检查无DEV/全局调试桥、无页面错误。四视口1280×720、1920×1080、844×390、915×412；五主题边界截图、加点保存重载/切人/重置和战斗快照已检查。

首轮修习用例错误地期待刷新后自动读取隔离调试键，已改为正式存储键验证，不改产品读档策略。另有一次WebKit844视口点击未触发CD，未改源重复三次及整批复查通过，偶发原因未确认，记录保留。地面初试拉伸纹理被截图检查否决，最终换成独立生成图，拉伸试案没有交付。

## 未验证与下一步

没有Android/iPhone真机、FPS/发热、真人扬声器试听/合成发力审美、新版自然鼠标完整十关和配点最终平衡。Windows WebKit缺AudioContext，检查HTMLAudio后备对象和资源，不能替代Safari真机听音。人物没有增加完整动作帧，普通敌方补帧仍待做；道路/背景会横向循环，无建筑内部碰撞或复杂寻路。

下一次先根据真人反馈校准普攻与技能音量比、短喊是否自然、缩小人物在手机上的辨识度及加点选择；继续追踪WebKit偶发点击，不要靠自动重试掩盖重现缺陷。暂不扩第二章或额外货币体系。
