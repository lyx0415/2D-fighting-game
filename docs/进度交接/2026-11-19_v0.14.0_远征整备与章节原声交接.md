# 2026-11-19 / v0.14.0 远征整备与章节原声交接

## 本轮落地

- 选关后进入画面化出征单。契约、敌军图鉴、队伍与领队集中在同一处。工坊和修习可以往返出征单，奖励栏和出发按钮固定。
- 灰烬主题使用新生成封面。战场背景加入视差和随主题变化的余烬、薄雾，均在可行走范围上方。
- 《余火行路》加入营地和战斗。Web Audio 根据遭遇状态混入战斗声部，两位首领分别使用新预警和结算音。暂停期间可修改四路混音，旧存档可直接继续。

## 已验证

97 项规则检查通过。浏览器合计 Chromium 62 项、Windows WebKit 59 项通过，WebKit 按配置跳过三项。新档用自动化发出真实鼠标事件通过前三关，未注入伤害和奖励。最终生产构建在两引擎实际开战，Chromium 验证断网启动并加载新版素材。本地生产包保存在 `artifacts/ashen-oath-v0.14.0-web.zip`。

## 工作入口

界面从 `src/ui/expedition-briefing.ts` 和 `src/ui/sound-settings.ts` 出发。章节分层与播放状态在 `src/game/chapter-score.ts`，首领声映射在 `src/game/audio-cues.ts`。声音通过 `npm run audio:score` 重新渲染。执行浏览器截图用例后可运行 `npm run assets:export`，该命令更新 v0.14 导出和总图鉴。

生产包也由 [GitHub 主分支构建](https://github.com/lyx0415/2D-fighting-game/actions/workflows/ci.yml?query=branch%3Amain) 提供，工件名为 `ashen-oath-web`。

## 待验收

Android Chrome 与 iPhone Safari 真机扬声器、耳机听感、帧率和发热仍待验证。浏览器测试断言素材解码、状态切换及操作，真人试听再确定配乐的循环耐听度与不同设备响度。第二章仍在规划。
