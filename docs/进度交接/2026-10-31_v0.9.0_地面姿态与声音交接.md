# v0.9.0 地面、姿态与声音交接

2026-10-31。用户要求缩小人物、明确走道/背景、增加多向脸型姿势、差异音效/环境声及约1秒入场。已实现并更新生产包。

## 已实现与入口

- scene.ts：英雄缩小26.4%，敌人/Boss相应缩小；可走带提亮、路外暗化、石屑与灯点边界、接地阴影/场景色调；地面随镜头1:1滚动，保持FLOOR不变。
- painted-character.ts、raster-art.ts：新10格多向待战，低血量戒备；UI使用5张新立绘。移动与攻击继承v008，无数值变化。
- audio.ts/audio-assets.ts：39音效、6环境循环，本地样本实际播放、音量/暂停/切换场景、HTMLAudio后备。audio-cues保留事件映射及样本缺失回退。
- main.ts/chapter-entry.css：资源加载和1050ms双条件、加载保护、进度/章节信息、失焦和取消回调处理。

新增图像真源public/assets/v009，音频真源public/audio/v009。旧v008目录保留使用；生成原稿/提示词、jsfxr来源许可、声音配方与分类副本已保存。以前的源和清单快照在artifacts/v008-before-v009。

维护命令：npm run art:stances；npm run audio:build；npm run build；浏览器截图后npm run assets:export和npm run art:preview；python scripts/verify_archive.py。生成器不影响常规启动所需依赖。jsfxr为离线Unlicense工具，不是运行时插件。

## 实际验证

58规则通过；两引擎38项既有玩法/绘制回归、最终8项入场/声音/生产专项通过，共46个不同用例。检查加载不计时、失焦保留暂停、尺寸与姿态URL、路外移动拒绝、音频45文件与39样本实际解码（Chromium）、静音/环境切换。WebKit缺WebAudio，检查HTMLAudio后备对象和WAV可用，不能替代Safari真人听音。

音频45文件PCM分析与独立哈希/链接校验另存artifacts。清单数量和最终结果见TEST_REPORT，不把音效差异指纹当真人听感验收。

## 限制与下一步

没有自然重跑完整三/十关、没有Android/iPhone真机/FPS/发热与真人听感/动作审美验收。新多向姿态用于待机和低血量，攻击移动仍侧向有限帧，未做自由转身系统。普通敌方完整步行/攻击帧仍待补。地面边界是矩形走带，未新增建筑内部碰撞。

下一步优先真人试听音量和不同武器可辨性、手机人物尺寸与路面辨识，再继续补帧。双击启动游戏.cmd重新构建后游玩。
