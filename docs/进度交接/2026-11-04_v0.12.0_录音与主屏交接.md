# 2026-11-04 / v0.12.0 录音与主屏交接

## 当前可运行状态

源码、锁文件和dist均为0.12.0。当前内容仍是第一章十关、五职业选四、装备与修习闭环。本轮重点重做声音及标题/营地主屏，没有新增章节或改动战斗伤害、掉落、成长数值。

启动：项目根目录运行“启动游戏.cmd”，或npm run build后npm run preview；通过HTTP访问，不能双击dist/index.html运行。调试与正式存档继续隔离。主菜单首次交互后解锁音频，设置中可关闭发力或选择混音模式。

## 已实现

- 当前声音全部换至public/audio/v012：52基础cue、20真人变体，共72WAV。Foley材质、兵器、火/风/地牢环境与真人选段取代旧DSP发力。旧资源保留历史对照，没有复制商业游戏原声。
- 五职业发力/受击各3段轮换；发力仅主动角色大技能触发并节流，受击需真实掉血及伤害条件，普通攻击/命中低增益及距离衰减。持续防御与环境按状态收放；三混音模式兼容旧存档字段。
- 原创篝火骑士大背景、全屏标题场景、纵向菜单、手记/设置/致谢/可选全屏；营地中央舆图与底部队伍/启程突出，整备入口置于左侧。短横屏与减少动态偏好适配。
- 修复WebKit舆图反复返回时的浮点滚动漂移；没有放宽严格测试容差。
- 新图鉴提供同事件30秒旧/新音色对照、PCM RMS匹配版本、逐项技能/环境和3段真人录音选择、完整来源署名。
