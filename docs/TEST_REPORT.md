# v0.14.0 验证报告

2026-11-19，Windows，Node.js 24.18.0、npm 11.16.0。浏览器使用 Playwright 1.56.1 的 Edge/Chromium 与 Windows WebKit。

| 验证 | 结果 |
|---|---|
| Vitest 4.1.12 | 97 项通过 |
| 浏览器全量加补跑 | 121 项通过，3 项按测试配置跳过 |
| 自然通关 | Chromium 新存档用实际鼠标输入通过 1-1、1-2、1-3，无注入伤害或奖励，战斗用时分别为 65、73、78 秒 |
| Vite 7.3.7 | 生产构建通过，两引擎用生产版实际开战，无开发入口 |
| PWA | Chromium 获得 112 项预缓存，断网读取新插画、曲目、部分首领音效并开战 |
| npm audit | 官方源本轮返回 0 项已知依赖漏洞 |

首次全量运行的 Chromium 通关用例被开发热更新重载打断，在源码稳定后通过。另有四个 v0.5 布局用例仍使用旧成长页选择器，已对齐当前界面并在两个引擎重跑通过。三个跳过项均为 Windows WebKit，分别是仅在 Chromium 执行的鼠标完整流程、Service Worker 离线测试、Web Audio 离线波形导出。

出征整备覆盖 1280×720、844×390、915×412 与 390×844。验证更换领队、打开敌情、在修习中消耗点数、保留原契约与固定出发按钮。混音覆盖暂停中调节、退出设置、静音恢复和刷新保存。首领诊断用隔离测试进度进入典狱长战，确认从探索、遭遇到首领的配乐状态切换，以及预警和着地采样。
