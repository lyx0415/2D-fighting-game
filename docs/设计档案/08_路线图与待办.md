## 持续工程要求

每次同步设计、更新日志、交接和素材清单。运行真源仍为art.ts；不让导出图和运行图成为不一致双真源。生产变更需构建并实际开战；报告按版本和日期另存。完整鼠标流程较慢，必要时运行npm run test:chapter；不把特定算法通关等同真人体验认可。
