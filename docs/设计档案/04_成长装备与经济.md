# 成长、装备与经济

等级上限10；升级经验60/90/120/150/190/240/300/370/450，自动增加一级基础生命12%、攻击8%、护甲2，线性累计。营地可分配天赋与技能点，规则见下方v0.10修习章节。前三关通关全员经验60/90/130，候补也领取；新伙伴先与最高等级一致并从该级零经验起，再统一发本关经验。战斗中不升级改变属性。

每人武器/护甲/饰品三个槽；武器限定职业，其他通用。每件独立ID、不能同时穿两人，转移先卸下；替换旧装备留背包。初始与招募角色自带完整白装，首版背包无限，营地换装。

白/绿/蓝倍率1/1.4/2。武器攻击5；护甲生命30护甲4；饰品生命15攻击2。强化上限+3，每级增加未强化装备属性10%，三次费用40/80/120，100%成功。已穿戴不能出售，白绿蓝售价10/25/60，强化成本不返还。固定属性，无随机词条。

伤害顺序：等级成长→装备→天赋固定加成→升级后技能倍率→护甲→临时减伤→护盾→生命。公式与详细表见../BALANCE.md；源数据见src/core/data.ts和progression.ts。

普通/精英/Boss金币5/20/80，掉装8%/50%/100%。通关额外80/120/200金币，首通保底绿色战士武器/绿色护甲/蓝色饰品。白绿蓝概率分别80/20/0、55/40/5、30/55/15。装备三槽等概率，武器仅选择本场已有职业。

掉落短展示后自动收取，关内临时保存，胜利后用runId幂等结算。失败、放弃或刷新不保留本场奖励和临时伙伴，不扣已有资源。重玩仍有普通掉落、金币经验，不重复首通奖励。

后续评估天赋分支扩充、法宝与紫金红品质，每增加成长线必须定义资源来源、消耗和与现有数值的关系，不在样板中放无功能入口。

第4～10关经验和首通蓝装按[配置快照](../章节与数值快照.md)；升级与装备公式不变。旧版5级存档保留现有等级，从后续关卡获得经验可继续成长，不补发之前已截断经验。

## v0.4工坊交互

角色由带头像的常驻按钮栏切换。仓库集中为内部滚动的装备方格；部位、品质、已/未穿戴与仅当前角色可用组合筛选。点选装备显示与当前槽位属性差值，再装备、强化或出售；点已装备槽会清除筛选并选中当前物品。筛选不改变成长、资源或存档结构，换装/卸下/强化/出售继续即时保存。已占用不可转交、已穿戴不可出售、金币不足不可强化。


## v0.10 天赋与战技修习（当前实现）

等级每升一级获得1天赋点，总预算level−1；坚韧每点+职业初始生命5%（合计四舍五入）、锋芒每点+2攻击、铁壁每点+2护甲，各上限5点。10级共9点，不能全满。

2/4/6/8/10级各获得1技能点，总预算floor(level/2)；两个技能各可追加3点，等级1→4。每点使伤害/护盾/自身减伤效力+8%、基础CD缩短4%，线性累计。射程、控制、持续时间不变。坦克减伤从40%最高到49.6%；战士护盾从最大生命30%最高到37.2%。10级共5点，不能同时点满两个技能。

营地免费重置当前角色，返还全部预算，不改变金币、装备、经验。预算由等级减去已分配值计算，没有可重复领取的奖励计数器。旧SaveData.version=1沿用，可选talents和skillRanks缺省为0；现有等级立即提供未分配点数，不丢旧资产。新伙伴按原规则继承等级，分配为空。非法结构、超支或超过上限的档案拒绝读取并优先恢复有效备份。


源规则training.ts、属性progression.ts、技能battle.ts。修习仅能在营地操作；出战和候补各自拥有独立点数。现有三级/满级调试档均保持未分配，便于比较加点前后。
