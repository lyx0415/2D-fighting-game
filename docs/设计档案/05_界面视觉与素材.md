# 界面、视觉与素材

## 页面分布

标题（继续/新游戏覆盖确认/声音）；三幅可跳过序章；远征地图主屏（章节节点/主线目标/底部启程）；次级整备面板（战斗配置/装备仓库/英雄成长）；出战准备（四人/队长/提示）；战斗（头像血条/波次/暂停/两技能）；结算（金币经验/装备/新伙伴/首通）。

手机横屏、安全区域、实际触控区至少48 CSS像素；竖屏提示并暂停，旋回后手动继续。目标圈/主动光圈/CD/预警必须辨认清楚，伤害数字限量，品质同时用颜色和文字。中文系统字体优先，不依赖外部字体。

## 统一美术

蓝黑、冷铁灰与旧金，低饱和背景、深轮廓和金属亮面。职业通过剑弓杖盾双刃区分；敌祭司暗红，狼四足，Boss宽肩重甲、角冠双链。当前英雄256×320、脚底(128,300)，敌人128×160、脚底(64,150)，右朝向、左向镜像，透明底。当前五英雄与十种敌人用连续关节运动，英雄有双节IK及足部轨迹；80张英雄图是同源静态采样，不作为运行帧图集。均不宣称手绘逐帧或顶点蒙皮。

地图1920×720，天空月光→远景→建筑树木→雾→碎石地面→前景草丛。战斗通道y360～620，装饰不作隐形障碍，前景不遮预警与血条。

音效来自src/game/audio.ts本地合成，覆盖点击、攻击、箭、法术、受击、掉落、死亡、胜败；首次交互解锁，可调音量。无录音配音或背景音乐；v005已导出同源合成WAV试听，见本文件最新记录。

## 素材工作流

见../../素材库/README.md、00_规范/统一美术规范.md与catalog.json。人物、装备、地图背景、物体、UI、剧情、音效分类。每项记录ID、来源、状态、文件位置和SHA-256。

运行源当前仍是src/game/art.ts；素材库是同源导出与参考归档。修改导出图不等于修改运行源，除非一起迁移加载。装备裁切含手部衣物，须标成参考；截图是运行参考，不是可直接拼UI的切图。每次更新日志记录素材是否已接入。

## v0.4职业面容、动作与工坊

战士方颌、坦克宽厚老将脸、刺客窄颌高颧、射手椭圆脸、法师修长面型；继承原头饰与职业服饰。hero-art.ts提供7种姿态、16帧/人；hero-motion.ts根据模拟时间采帧，scene.ts缓存并播放。走路、普攻、小技能、大技能各有肢体与武器差异，不再仅依赖整张图晃动。

右下双技能采用职业铭牌与稍大徽印、战术标签和径向CD，按职业变化色调与边框；手机短屏紧凑布局。工坊桌面三栏、小屏两/单栏：角色/装备槽、集中仓库、详情比较。角色栏和筛选按钮代替下拉，仓库自身滚动，不再一件物品占一整行。
