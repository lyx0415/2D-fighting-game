# v012：录音与Foley素材主体重制

日期：2026-11-04。状态：72个运行WAV及四份30秒对比混音（原电平与RMS匹配各一对）已生成，离线数据检查通过。真人听感、游戏播放与移动设备验证，以本轮最终测试/交接为准。

## 本轮方向与文件

用户拒绝v011声音的突兀、蜂鸣和合成发力质感。本轮改为取得合法源音频后，进行剪辑、材料叠层、频段与响度控制。运行音源没有调用旧版声音生成器，没有混入旧SAPI或声门模拟；旧版本仅用于标明历史版本的对比试听。

- 运行目录：`public/audio/v012/{cue}.wav`，默认单套`foley`，扁平路径。
- 清单：`public/audio/v012/manifest.json`。52个基础cue完整覆盖既有46效果音与6环境，另有20个人声变体，共72个运行WAV。
- 变体：5职业的`Exert`、`Hurt`各3段，基础文件加`__2`、`__3`，例如`warriorExert.wav`、`warriorExert__2.wav`、`warriorExert__3.wav`。
- 每项清单保存`id/baseId/variant/profile/file/seconds/duration/peak/rms/sha256/source/loop`。`source`列出实际原稿文件、哈希和所选许可；没有把来源笼统写成原创录音。
- 制作脚本：`scripts/build-audio-v012.py`。以保存的原稿离线重建，不访问网络，缺少原稿直接报错，不静默换回旧DSP。
- 原稿/压缩包/许可和网页证据：`tools/audio-sources/v012/`。获取工具为其中的`fetch-sources.py`，Kenney按页面公开的download-link端点取得签名下载地址，验证ZIP格式后解压；未绕过登录或付费限制。
- 署名文件：`public/audio/v012/CREDITS.txt`。运行界面的制作名单由主任务同步。

## 材质、节奏与混音

普通攻击约0.15–0.45秒，以短干的衣料、刃面、木质释放为主，避免四人持续作战时铺满回响。伤害生效音使用独立命中cue，不将每次挥动都做成重击。

- 战士：刀面与衣料破空，命中配身体冲击；横扫有短起势、切入与克制空间尾。
- 射手：木质拉动/释放与衣料气流组成放箭；连射、箭雨采用分次事件感，落点带木箭与躯体层。
- 法师：冰使用玻璃细碎材料与空气，火使用已有火焰原稿和柔软低频冲击。`meteorCast`只有蓄力与下坠空气，不含提前爆发；0.7秒后的实际伤害由`fireHit`承担。
- 坦克：盾板、柔软重击和皮带材料组成厚重防御与盾震，削弱响亮的高频金属钟声。
- 刺客：短刃与衣料、轻微反向抽离构成快速影袭；处决保留双刃间隔与命中分层。
- UI：点击短促，奖励使用钱币与书页触感，失败使用合书/皮革落地；胜利不加入电子旋律。

全体源先去无声头尾并做输入电平整理。最终宽带削弱1.5–4kHz约46%的滤出分量，并使用45/65Hz高通与6.8kHz低通；这是宽频段处理，不能等同于逐个声源精准消除所有刺耳共振。

| 类别 | 峰值上限 | RMS上限 | 备注 |
|---|---:|---:|---|
| 普通攻击 | 0.24 | 0.052 | 短且偏干 |
| 常规命中 | 0.32 | 0.075 | 冰火命中保留更长材料尾 |
| 技能/敌人特殊攻击 | 0.57 | 0.13 | 材料层次、厚度与短空间感 |

| 防御持续 | 0.10 | 0.022 | 2秒轻风低音循环 |

## 真人声音变体

HaelDB压缩包包含多个男性录音组。本轮战士选`1yell`短段、法师选`3grunt`、坦克选`2yell`短段，保留各组原声，没有通过大幅降调制造兽吼。具体切点在`male-voice-segments.json`，对应原文件路径在每cue清单中。

SkyRae原音频约4.92秒，依据波形起止识别多次非语言发力并裁切，分配射手和刺客；是同一女声素材库中的不同片段，不能称为两位不同演员。男女片段均根据原标签、波形和短时长选择，未完成真人逐段听感认定，不把“受击”用途标签等同于演员明确演绎过该技能剧情。

发力与受击每角色各3段，运行时可轮换，不能每次普通攻击都高频叠加。使用真人录音消除了旧TTS朗读源，但自然度、情绪和与立绘是否匹配仍需用户试听。

## 持续声与章节环境

`wardSustain`、`oathSustain`均为准确2秒的低频风录音编辑循环，不含振荡器蜂鸣或重复起势打击。护盾6秒、誓言5秒由运行状态控制生命周期；开始/停止、角色倒地、暂停、离开战斗时需淡入淡出并停止节点。

6个环境准确12秒：营地是轻篝火与低风；焦土更重风和余火；雾林以较宽风/叶片感为主；要塞与修道院有很轻的木构件远层；地牢保留来源环境的风与水滴。没有新增电子旋律或声门持续音。

循环采用录音叠接、短交叉淡化与接缝校正；不会把“首尾数值相等”直接宣称为听觉上完全不可察觉。

## 30秒对比：保留原电平，增加RMS匹配

- 历史版：`public/audio/v012/previews/encounter-historical-v011-30s.wav`。
- 新版：`public/audio/v012/previews/encounter-foley-v012-30s.wav`。
- 事件表：同目录`timeline.json`。同一30秒脚本、同一0.8主增益、相同角色/技能/普攻/命中事件安排。

两份是**离线构造的遭遇试听混音**，不是浏览器实战录音。历史版读取v011 grounded及其原有v010共有cue；新版读取全部v012。保留实际文件电平差异，没有响度配平。当前历史RMS约0.05476，新版约0.01870，故新版明显更安静；这一差异包含缩短干声和电平控制的影响，不能据此宣称音色审美已验证更优。

用于比较音色的同RMS版本另存为：

- `public/audio/v012/previews/encounter-historical-matched.wav`：量化后RMS `0.01999939`、峰值`0.13568115`。
- `public/audio/v012/previews/encounter-foley-matched.wav`：量化后RMS `0.01999938`、峰值`0.35528564`。

两份统一目标为30秒整段线性PCM RMS `0.02`，历史版乘以约0.365235、新版乘以约1.069281；没有限幅器或动态压缩，均无削波。最终量化后两份RMS相差约`1.19e-8`，约`0.0000052 dB`。manifest对应项标记`rmsMatched:true`、`targetRms`、`appliedGain`与方法说明；原电平版本标记为false并继续保留。

**PCM RMS匹配不等同于LUFS或感知响度匹配**。频谱、瞬态、静默比例和材料变化仍会使耳朵感知不同响度；此版本消除的是原先约9dB的整段RMS差异，不能宣称完成感知响度测试。

- 独立读取72个运行文件，清单时长、峰值、RMS、SHA-256全部与量化后PCM吻合；没有空文件或满幅削波。
