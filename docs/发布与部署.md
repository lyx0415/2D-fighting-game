# v0.13.0 发布与部署

## 本地与手机

Node.js 24、npm ci、npm run build、npm run preview。电脑访问命令显示的地址；同局域网手机可用电脑IP访问横屏游玩。HTTP局域网不提供可靠PWA安装/Service Worker；正式环境须使用HTTPS，localhost为开发例外。

## 生产

将dist完整内容部署在HTTPS站点根目录。当前美术、音频、manifest和SW使用根路径；不要未经修改部署到GitHub Pages项目子路径。服务器为sw.js提供no-cache响应头、JS正确MIME，禁止将缺失资源统一伪装成HTML。GitHub上传不等于公网托管或商店上架。

105个核心文件约16.3MB原始字节（见artifacts/pwa-build.json），包括当前全部26位图、72声音、脚本/CSS/图标/HTML/manifest。首次联网完整安装Service Worker后可离线开战。浏览器可清理缓存和进度；定期导出存档。历史音效及预览不参与预缓存。

缓存按构建内容哈希区分；新SW等待旧页面全部关闭后接管，不在战斗中强制重载。安装失败时继续联网游玩，设置/进度页可看状态；首次未完成缓存时不能承诺离线。断网冷启动已做Chromium自动化；iOS/Android实机与系统安装入口仍待测。

## 进度管理

标题页“进度管理”导出JSON；另一设备选择导入文件，校验后展示同伴/关卡/金币摘要，确认覆盖，旧有效存档作为本地备份。拒绝>1MB、坏JSON和非法规则数据。没有云同步；切换域名或浏览器必须手动转移。

## 版本验证及仓库

npm test、npm run build；npx playwright test e2e/release-v013.spec.ts e2e/production.spec.ts用于手机视口、存档和生产离线。Windows WebKit不支持Service Worker测试时明确跳过。CI自动做规则/构建并上传dist工件，不假装已做真机测试。

源码、分类素材和历史记录可上传；node_modules、构建临时缓存、Python离线解码依赖、浏览器trace和修改前快照保持本地。素材生成若需SoundFile可用pip安装soundfile==0.14.0，运行游戏无需Python。没有上传用户存档、访问令牌或本机浏览器状态。


## 备份恢复

在标题页进入“进度管理”，选择“恢复上一份”。先核对进度摘要，再确认恢复。恢复会把当前有效进度放入备份。相同内容的保存不会轮换备份。
