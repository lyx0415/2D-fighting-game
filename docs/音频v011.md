# v011：三套可选技能、打击与发力音色

日期：2026-10-31。素材状态：已生成、已完成独立PCM及哈希检查。运行时选择、试听UI、持续声生命周期、最终混音和浏览器验收由本轮主任务维护，本文不将素材检查写成真人听感通过。

## 文件与接入约定

- 真源：`public/audio/v011/{profile}/{id}.wav`。
- 三套`profile`：`grounded`沉稳写实、`feral`粗砺战吼、`mystic`秘仪回响。
- 各24项，共72个WAV。清单`public/audio/v011/manifest.json`包含`profile/id/file/seconds/peak/rms/sha256/source/loop`；同时保留`duration`别名便于既有素材工具读取。
- `file`相对v011目录，例如`grounded/wardSustain.wav`。根目录清单不是旧版扁平文件结构，接入时需带所选profile。
- 原v010的其余28项保持原路径，由运行时继承，本次没有复制或修改它们。v010所有文件与生成器原样保留。
- 生成器：`scripts/build-audio-v011.py`。运行`python scripts/build-audio-v011.py`，需要NumPy和SciPy。固定种子110131，各`profile/id`独立派生随机种子，不依赖SAPI、下载服务或v010原稿。

## 三套声音方向

| profile | 材料与空间 | 发力声方向 |
|---|---|---|
| grounded | 低频身体感、偏干燥的木弦/刃面/盾体与短残响 | 正常音高，轻微不规则声门，紧凑呼吸起音 |
| feral | 增强厚度、饱和颗粒、粗糙冲击与少量残响 | 较低音高、更明显声门粗糙与胸腔次谐波；时长略增 |
| mystic | 气流、共鸣、相对较轻的身体感与更长空间尾 | 较明亮音高、柔和气息、低音量短回声 |

三套每个同名cue均单独生成，文件哈希各不相同。它们提供可选择的音色方向，不意味着已经证明某一套听感优于另一套。

## 发力声：重新生成，未混入旧SAPI

新增/替换发力ID仍为`warriorExert`、`archerExert`、`mageExert`、`tankExert`、`assassinExert`，每套均有5项。

本轮完全采用**原创声门源/共振滤波与气息DSP**，不再使用SAPI的“嘿哈咻”朗读音节。结构是呼吸起音→短促有声发力→气息释音；加入平滑但不规则的基频变化、振幅变化、声门粗糙度与不同元音共鸣。仍属于模拟发力的合成声音，**不是人类演员录音，也不能称作真人战吼**。

## 两种持续防御层

- `wardSustain`：护盾期间的低音气息与保护共鸣，预期配合6秒buff。
- `oathSustain`：更低沉的誓言/守护音层，预期配合5秒buff。

每套各有两个**准确2秒、单声道、可循环**的PCM。FFT周期频带、整数周期低音与0.5/1Hz周期缓动构成，无直流与首尾淡出；在生成时选取较安静且相邻采样差小的循环点。素材不会自行结束于buff持续时间，需要运行时在状态结束、角色倒地、离场或暂停时停止/淡出，重复施加只刷新同一层，避免叠加。

循环峰值上限0.19、RMS上限0.043，仍建议运行时比施法起音更轻。开始与停止需由混音层使用短淡入/淡出；源WAV不包含起势冲击，防止每2秒重复出现敲击感。

## 许可、溯源与验证

72个WAV均由本轮脚本原创生成。没有下载第三方音效，没有使用真人录音，也没有使用SAPI或其他TTS输出；本轮不继承jsfxr波形。既有v010/v009许可保持原文，本文件不改变旧素材许可。生成器及manifest保留方法、固定种子与完整文件哈希。

2026-10-31，使用本机Python/NumPy/SciPy完成：

- 全部72项为22050Hz、单声道、16位PCM；文件非空、数值有限、峰值小于1，无满幅削波。
- 独立重新读取并核对72项时长、峰值、RMS与SHA-256，全部一致。
- 每套24个ID，无重复或遗漏；同一cue的三个profile哈希各不相同。
- 同原稿条件重复运行生成器，72个WAV与manifest逐字节一致。
- 6个循环均44100采样。最大首尾相邻采样差`0.00003052`（归一化PCM），最大直流均值绝对值约`0.0000000554`；这是接缝数值检查，不等同于真人确认无感。
- 运行WAV合计3,640,696字节，约3.47MiB。只需预载当前profile和共同v010音源，无须把全部试听版本同时作为战斗常驻层。
