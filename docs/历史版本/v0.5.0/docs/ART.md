# 原创美术资源说明

本样板的全部图形均为项目内手工编写的 SVG / 几何图形，不引用外部图片、字体或版权角色。资源可以与项目一同修改和分发。

## 导出接口

- `characterSvg(kind)`：英雄返回256×320、脚底(128,300)；敌人返回128×160、脚底(64,150)，均右朝向。支持 warrior、archer、mage、tank、assassin、zombie、wolf、crossbow、priest、raider、guard、boss；未知值回退为战士。
- `portraitData(kind)`：返回上述角色的安全编码 SVG Data URL，可直接用于 HTML 图片。
- `sceneSvg(theme)`：返回 1920×720 场景；ash、forest、fortress 分别表现灰烬村道、雾林囚车、黑石哨站。战斗地面处于 y=360..620，画面左右地面色调一致，可连续铺设。
- `crestSvg()`：返回 160×190 王印徽记。
- `storySvg(index)`：返回 1920×720 的三幅原创剧情插画（0：公主与王印；1：黑潮教团；2：战士追赶）。图像不包含文字，叙事文字由页面绘制。

## 视觉规则

整体使用蓝黑、冷铁灰与旧金；背景压低饱和度，角色用清晰深色轮廓及金属亮面分离。五职业通过剑、弓、法杖、盾锤与双刃区分。敌方祭司以暗红衣袍和红色法器区分；狼采用独立四足轮廓；典狱长采用宽肩重甲、角冠与双锁链，区别于精英盾卫。

背景自远向近包含天空、月光、远景轮廓、建筑或树木、雾层、地面碎石与前景草丛。囚车、牢门等可辨识装饰位于战斗通道边缘，不构成隐形障碍。背景纹理用确定性的函数生成，同一主题在每次启动时保持一致。

角色动画由表现层播放英雄有限帧部位姿态，敌人仍使用整体变换。当前资产是具象简美术，不声明为逐帧手绘或连续骨骼动画。

## v0.4职业面容与有限帧动作

入口characterSvg/portraitData继续返回新待机造型；heroSvg(kind,pose,frame)在hero-art.ts提供7种姿态、每人16帧/共80帧。256×320与脚底128/300不变，头部、身躯、双臂双腿、武器、披风与袍摆可分别变换。脸型和动作差异见[英雄美术v004](英雄美术v004.md)。hero-motion.ts按模拟时钟采帧，scene.ts预载80张姿态纹理；伤害和碰撞仍使用地面坐标，图形不反过来改变战斗判定。

## v0.5当前运行美术

hero-art.ts/hero-rig.ts与enemy-art.ts分别提供heroRig/heroRigMotion与enemyRig/enemyRigMotion，统一类型rig-types.ts。rig-renderer.ts用Phaser容器建立关节父子链，hero-motion.ts选择相位，scene.ts实际接入十五种角色；英雄93层、敌方126层。heroSvg的80图为连续运动静态采样，同源geometry，不再作为战斗帧切换方案。

面部刻线、伤痕和岁月细节、站姿与动作见[英雄v005](英雄美术v005.md)和[敌方v005](敌人美术v005.md)。combat-effects.ts为事件驱动图形，audio-cues.ts和audio.ts为33种音色配方和实时合成。运行全部本地，不引入外部图片/字体。没有录音、配音或蒙皮声明。

art:preview生成hero-v005-preview.html和可离线播放/暂停的rig-v005-preview.html；后者将连续运动按41个时刻插值呈现，游戏本体每帧实时计算。assets:export按人物/关节分层/设计对照/音效分类导出。
