# 界面、视觉与素材

## 页面分布

标题（继续/新游戏覆盖确认/声音）；三幅可跳过序章；远征地图主屏（章节节点/主线目标/底部启程）；次级整备面板（战斗配置/装备仓库/英雄成长）；出战准备（四人/队长/提示）；战斗（头像血条/波次/暂停/两技能）；结算（金币经验/装备/新伙伴/首通）。

手机横屏、安全区域、实际触控区至少48 CSS像素；竖屏提示并暂停，旋回后手动继续。目标圈/主动光圈/CD/预警必须辨认清楚，伤害数字限量，品质同时用颜色和文字。中文系统字体优先，不依赖外部字体。

## 统一美术

蓝黑、冷铁灰与旧金，低饱和背景、深轮廓和金属亮面。职业通过剑弓杖盾双刃区分；敌祭司暗红，狼四足，Boss宽肩重甲、角冠双链。当前英雄256×320、脚底(128,300)，敌人128×160、脚底(64,150)，右朝向、左向镜像，透明底。当前五英雄与十种敌人用连续关节运动，英雄有双节IK及足部轨迹；80张英雄图是同源静态采样，不作为运行帧图集。均不宣称手绘逐帧或顶点蒙皮。

地图1920×720，天空月光→远景→建筑树木→雾→碎石地面→前景草丛。战斗通道y360～620，装饰不作隐形障碍，前景不遮预警与血条。

音效来自src/game/audio.ts本地合成，覆盖点击、攻击、箭、法术、受击、掉落、死亡、胜败；首次交互解锁，可调音量。无录音配音或背景音乐；v005已导出同源合成WAV试听，见本文件最新记录。

## 素材工作流

见../../素材库/README.md、00_规范/统一美术规范.md与catalog.json。人物、装备、地图背景、物体、UI、剧情、音效分类。每项记录ID、来源、状态、文件位置和SHA-256。

运行源当前仍是src/game/art.ts；素材库是同源导出与参考归档。修改导出图不等于修改运行源，除非一起迁移加载。装备裁切含手部衣物，须标成参考；截图是运行参考，不是可直接拼UI的切图。每次更新日志记录素材是否已接入。

## v0.1.1已接入更新

7张独立装备图标已用于装备槽和行囊；旧裁切仍保留参考状态。护盾增加包围轮廓，掉落光点飞向主动角色，近战命中和技能提供颜色反馈。漂字最多30对象、环形特效最多24对象并循环复用；暂停时冻结这些补间和角色摆动。结算显示实际模拟战斗用时。素材库共44项。

## v0.2.0十关版本

地图扩至十关并分三段提示：集结同伴、钟楼与回廊、地下与圣殿。新增5份运行艺术：狂信徒、怨灵、主教人物，以及修道院玫瑰窗/钟楼、墓道拱门/遗骨/烛火两个场景主题；均与原冷铁灰和旧金统一。素材库含50项（其中15人物、5地图、7界面截图）。新主题仍由art.ts生成，并同源导出归档。

## v0.3.0五项反馈落实

整章不再用关卡卡片网格：一张蓝黑地形舆图有10个按钮节点和9条连接；最终Boss节点78px大于普通48px节点。已通/当前/锁定同时用状态色、图形与aria标签表达，小屏横向查看，点击仍进入出战准备。地图包含同章森林、村庄、堡垒、回廊和圣殿细节。

UI主色蓝黑、旧金边饰；中文采用本机中宋/宋体回退，英文Palatino/Georgia衬线铭文风。不宣称安装了新字体。标题、营地、装备、弹窗与战斗HUD整体统一。

五英雄v003形象明确差异，新增十个职业技能图形、战术标签和颜色；各职业原本独立的HP/攻击/护甲/技能范围与CD仍保留，不虚构额外元素克制。战场使用高分辨率矢量纹理，未制作逐帧动作。

石道格纹、金线、边缘路灯和暗化路外定义可走区域；路外移动命令会给出提示。旧50项素材保留历史，新图标和界面版本独立记录。

## v0.4职业面容、动作与工坊

战士方颌、坦克宽厚老将脸、刺客窄颌高颧、射手椭圆脸、法师修长面型；继承原头饰与职业服饰。hero-art.ts提供7种姿态、16帧/人；hero-motion.ts根据模拟时间采帧，scene.ts缓存并播放。走路、普攻、小技能、大技能各有肢体与武器差异，不再仅依赖整张图晃动。

右下双技能采用职业铭牌与稍大徽印、战术标签和径向CD，按职业变化色调与边框；手机短屏紧凑布局。工坊桌面三栏、小屏两/单栏：角色/装备槽、集中仓库、详情比较。角色栏和筛选按钮代替下拉，仓库自身滚动，不再一件物品占一整行。

v003完整74项素材快照与原清单保留99_历史版本/v0.3.0，源码采样不是完整旧代码。新增v004静态立绘与75个非待机姿态分帧，合计80份英雄SVG，分角色存于人物/动作；图鉴从源代码导出。参考截图始终标明开发/生产与用途，不当作独立UI切图。

## v0.5远征主屏与战斗反馈

移除常驻左侧三个并列栏目。章节地图占主屏，底部出战队列与启程按钮建立主次；战斗配置、装备仓库、英雄成长以可收起整备面板叠加地图，底部入口保持可用。成长展示真实等级经验与职业技能；天赋状态明确为后续开放，不展示不可用点数。手机短屏压缩辅助说明并保留地图横向查看。地图SVG和连线路径使用同一非等比坐标投影，按钮中心与路径端点回归校验。

五英雄93层、十类敌人126层，共219运行层。英雄足部支撑/摆动与肩肘双节求解，敌人有独立蹒跚、狼四足、远程射击、念咒、重击/盾冲/Boss施法。站姿各异，五官增加眉骨、眼窝、鼻梁、嘴角和下颌线，辅以疤痕、雀斑、年龄线或符印。角色仍是二维原创矢量。

音效33种配方，用噪声、音高滑变和分层合成区别武器、十技能、金属/肉体/箭/冰火命中；同种短节流与24并发上限，避免全局节流吞掉施法声。程序特效区分斩弧、爪痕、箭迹/箭雨、护盾纹、冰晶、火星、暗影和受击碎屑；最多64组瞬态效果，血条与敌方危险预警独立保持可读。

素材导出包含同源219关节层及父子/pivot清单、静态采样、可离线播放的十五角色动作图鉴、33份WAV试听和新主屏截图。运行音效继续实时合成，WAV为同配方离线试听。v004完整166项清单与对应图像快照保留，历史源码采样不冒充完整可运行备份。
