# 操作、战斗与AI

## 输入契约

点地面设置目的地、清除追击，移动期间不自动停下普攻，到达后攻击范围内目标。点敌人锁定追击，进入射程自动攻击；敌人死亡清除锁定。点技能优先使用射程内锁定目标，否则最近合法目标；无目标不入CD，自保不要求敌人。

施法成功立即开始CD，连点不重复；短动作期间移动指令延后执行。头像切换不暂停、不重置CD；原角色转AI，新角色清除AI追击等待命令。UI不穿透地面。主动倒地切换下一存活成员，全灭失败。

## 空间与推进

1280×720设计坐标，战区宽2200，地面y360～620。二维距离与实际命中位置判定，按脚底y排序。首版无内部阻挡和复杂寻路。镜头跟随主动角色并限制地图边界。

清场后主动向右走入下区；存活队员回20%最大生命，倒地队员35%站起，CD不重置。Boss战内不自动复活，进关全生命与技能就绪。

## AI

危险躲避→合理技能→攻击→跟随。0.1秒决策，预警出现0.35秒后尝试躲避，不保证成功。主动角色不自动躲。战士坦克近战、射手法师维持距离、刺客偏好远程敌人，优先集火玩家目标；离主动角色超过420归队，无敌时松散跟随，软分离不硬阻挡。

战士低于55%生命用大招；坦克附近敌人攻击其他队员时嘲讽；输出大招用于精英/Boss/三个聚集敌人。AI与玩家共用技能伤害逻辑。

## 敌人与Boss

尸兵慢速近战；腐狼快速接近；弩手远程后撤；祭司每6秒治疗范围内最低生命比例敌人10%最大生命。掠夺者0.9秒扇形重击，盾卫1秒直线冲撞。

典狱长循环：裂地斩矩形预警1.2秒/150%；锁链震荡半径160预警1.5秒/120%；召唤两尸兵，存活时不重复召唤。半血狂怒，间隔缩短20%。同时最多一个特殊技能，预警锁定后不追踪玩家，技能间有普通战斗窗口。

同一步先完成伤害，再判全灭、最后判清场；双灭失败。每波唯一生成，每场唯一结算。初始数值与公式见../BALANCE.md。

## v0.2.0后半章敌人

狂信徒为快速近战；怨灵为精英远程，周期在当前目标脚下锁定半径82圆阵，1.2秒后90%攻击伤害。施法者死亡取消危险区。

章节Boss黑潮主教·莫尔：脚下圆阵（半径125、1.5秒、135%）、直线逆誓裂隙（长490宽100、1.25秒、160%）、召唤一怨灵一狂信徒。召唤物存活时不重复召唤，半血进入狂怒。预警位置在起手时锁定；两个Boss均免眩晕、减速减半，HUD使用各自名字和血量。

结算显示本关用时；第10关标题显示第一章完成，按钮改为查看队伍，不再误导为刚获得新伙伴。

v0.3.0：路外点按拒绝移动，石道边缘与FLOOR共用边界；普攻动作中的主动技能点按短缓冲，移动/切人可取消。小队实际承伤、护盾吸收和击败数记录在当场统计，不进存档。敌人新数值与缩放见BALANCE.md。

## v0.4动作表现约定

战斗模拟只新增不参与数值计算的action（普攻/技能0/技能1及表现起止时刻）。原操作锁定、伤害时刻与CD不变。表现根据模拟时间选择职业姿态；移动命令生效后展示步态，死亡优先。暂停不播放动作。技能CD与攻击动作分离，切人不重置，普攻短锁定内原有技能缓冲继续生效。
