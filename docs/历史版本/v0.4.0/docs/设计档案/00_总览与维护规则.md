## 持续维护约定

设计档案记录长期意图与约束；交接报告记录每次工作结束的真实快照；数值实现以src/core/data.ts和计算模块为准。设计与实现冲突时写明差异，不把规划说成已实现。

状态统一使用：已确认、已实现、已验证、待验证、规划中、参考素材。验证必须注明日期、环境和方法；模拟、桌面浏览器、手机真机与人工审美不可互相替代。

每次工作先阅读最新交接与待办，结束时更新受影响设计文件、追加更新日志、新增交接记录。素材变更同步catalog.json、图鉴与来源；测试报告需要留存时按日期另存，避免同名覆盖。

更新日志至少包含：需求原因、实际修改、涉及代码/素材、验证结果、实际限制与下一步。旧交接保留原状态，新进展写到新报告。不要因为目录存在就宣称其中的功能或成品已经完成。
