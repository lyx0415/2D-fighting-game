## 本轮实际覆盖

1280×720、1920×1080、844×390、915×412：地图保持3000/680比例，画布宽于窗口，邻节点CSS间隔至少185px；四入口合计50vw、互不重叠，点击区均≥48px，页面不横向溢出。左右浏览、定位、鼠标拖动、拖完不误开关卡、整备开关保留视野、路线端点与节点中心误差<2px、当前第四关打开准备均验证。

触屏tap选第一关、地面与路外指令、工坊/编队/成长入口、技能切人和UI不穿透沿用真实浏览器输入回归。触屏滑动使用原生overflow/touch-action；本轮未在Android/iPhone真机滑动验收，不以鼠标拖动替代真机手势结论。

五职业80动作采样能解码且透明画布边缘无裁切；15张头像声明128×144、均解码，去掉视角标记后每人的三种SVG仍各不相同；默认运行head与对应头像几何一致。浏览器截图人工查看了五人立绘、十五面容、桌面和手机宽图。连续关节/暂停冻结、敌人、技能音效事件和工坊流程通过既有回归。未另做735个中间相位的逐像素边缘检查，也不将静态图通过等同动作审美通过。

最终生产包在两引擎从正常新档进入地图、装备工坊并实际开战，初始战士与横扫正常，无DEV入口、全局调试桥或页面错误。更早同版矩阵也检查了修道院生产开战。未自然重跑新版前三关或完整十关；v0.5自然前三关69/76/75秒是历史成绩。

## 诊断与复核记录

初始专项3通过/4失败：平移使用平滑滚动时，紧接“定位当前”会残留7～19px偏移。改为确定的即时步进，定位不再与尚未结束的滚动竞争。

常规矩阵首次50通过/5失败/1跳过：短横屏新增浮动工具栏后，旧测试在工具栏区域拖动；另一个测试错误地要求WebKit SVG naturalWidth等于声明宽度。调整拖动输入到实际地图内，并同时检查声明尺寸和成功解码。游戏没有放宽节点对齐、半屏比例、拖动距离或解码条件。专项重跑10/10；再调整当前定位让下方普通节点标签尽量完整，最终构建后专项+生产12/12。额外跨出地图释放回归曾出现8通过/4个WebKit拖动失败；事件记录发现WebKit启动原生HTML dragstart而中止自定义平移；阻止地图原生拖放，并由window pointerup/cancel统一清理，最终复核覆盖该边界。原始诊断JSON均保留，最终汇总按“引擎+文件+用例”采用最近记录。

素材首次导出因缺少本版编队截图而中断，补录后完整重导出。校验脚本增加catalog版本和rig完整性检查；修正把rig_motion预览PNG误算成关节层的问题。最终941项、813项历史哈希与文档链接均通过，没有把中断导出写成完成。

## 音频与边界

Chromium同配方离线渲染33种WAV：非静音、指纹不同、单音无削波；当前Windows Playwright WebKit没有Web Audio API，对应测试明确跳过。音色本轮沿用，不能把重导出标成新增配方或Safari真机音频已通过。66份WAV中33份为历史版本。

未验证Android Chrome/iPhone Safari真机、FPS/发热、真人审美/动作自然度、自然通完新版章节和15～25分钟首玩目标。面容与地貌为二维SVG体积表现，未新增3D模型、动态转头、顶点蒙皮或新天赋玩法。
