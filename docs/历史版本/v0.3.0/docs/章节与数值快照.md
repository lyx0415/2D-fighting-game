## 剧情进出

### 1-1 灰烬村道

开场：押送队伍穿过了村庄。雷恩在灰烬中发现了一枚属于王室的断裂徽章。

结尾：薇拉：囚车往雾林去了。我认得那条路，让我和你一起。

教学：点地面移动，点敌人锁定。靠近后自动攻击，右下角施放技能。

### 1-2 雾林囚车

开场：腐败的树根缠住了囚车。铁笼里的学者正在用最后一点魔力抵挡黑潮。

结尾：布兰：公主还活着。他们把她带向黑石哨站。我的盾，愿为你们开路。

教学：点击上方头像切换角色。优先处理弩手和会治疗的祭司。

### 1-3 黑石哨站

开场：哨站深处传来锁链声。灰烬典狱长站在监牢门前，而公主的声音已经消失。

结尾：赛芙：你们来晚了一步。公主被转移到了修道院。教团要的不是赎金……是她手中的王印。

教学：留意红色地面预警，点空地躲避。典狱长半血后会加快攻击。

### 1-4 朝圣者旧道

开场：赛芙展开密信：教团会在下一次钟响时转移王印。小队沿废弃朝圣道赶往修道院。

结尾：薇拉：这些人不是被黑潮驱使，他们是自愿拥抱它的。钟楼就在前面。

教学：狂信徒行动迅速，保护后排，用范围技能压制聚集敌人。

### 1-5 无声回廊

开场：修道院中没有祈祷声。破裂的王印符文中，游荡着被仪式束缚的灵魂。

结尾：伊诺：王印留下了回响。公主来过这里，她试着破坏这场仪式。

教学：怨灵会在目标脚下留下诅咒预警。离开红圈，优先击破施法者。

### 1-6 钟楼封锁

开场：钟楼被精英教卫封锁。布兰发现一条通向地下墓道的旧阶梯，必须先夺回钟楼。

结尾：布兰：钟声会掩盖我们的脚步。走地下，公主留下的记号还没有消失。

教学：这是精英封锁战。集火祭司和怨灵，保留坦克大招应对围攻。

### 1-7 遗骨墓道

开场：地下墓道的墙壁刻满了失踪者的名字。赛芙认出了王室密探使用的暗记。

结尾：赛芙：公主在提醒后来的人——王印不是献祭的钥匙，而是关闭裂隙的钥匙。

教学：多个诅咒可能同时出现。别只顾输出，为队伍留出移动空间。

### 1-8 逆誓祭坛

开场：教团把守护誓词倒刻在祭坛上。伊诺必须夺回符文拓本，找到中断仪式的方法。

结尾：伊诺：主教把所有黑潮引向自己。击碎他的仪式，我们就能打开内殿。

教学：先压制远程施法，再处理重甲。切换刺客可更快接近后排。

### 1-9 黎明前庭

开场：小队从墓道重返地面。公主的徽记留在内殿门前，证明她仍在抵抗。

结尾：雷恩：走过来的每一条路，都不是徒劳。最后这道门，我们一起推开。

教学：最后的综合战。装备可以在营地强化到+3，合理切换和集火。

### 1-10 黑潮圣殿

开场：主教莫尔站在裂隙前，王印的光芒从祭坛后透出。仪式即将完成，这是阻止黑潮的最后机会。

结尾：莫尔倒下，裂隙暂时闭合。祭坛后只有公主留下的王印碎片与一封信：“去寒铁王城，真正的背叛者还在那里。”第一章·灰烬边境 完。

教学：章节Boss会锁定脚下的黑潮圆阵、释放直线裂隙并召唤怨灵。离开预警区域再输出。
