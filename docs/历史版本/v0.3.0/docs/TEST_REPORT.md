## 本轮覆盖

新增长战区、前后阵触发一次、未清后阵不能前进、一级英雄会受到实质伤害、8%普通回复/35%Boss前休整、路外移动拒绝、普攻动作内技能缓冲与移动/切人取消。原有成长/装备/存档/双灭/幂等/精英Boss机制保留。

浏览器四视口1280×720、1920×1080、844×390、915×412，覆盖节点地图9条连线/10节点/末Boss更大、触屏选关、头像卡片新图形/技能标签、旧档续关、装备编队、横竖屏与失焦暂停、生产初始关/新场景开战。实际SVG声明256×320且确已解码；WebKit可能按CSS显示尺寸报告naturalWidth，不能用固定naturalWidth判定其资源损坏。

种子42当前整章模拟约721秒，第一关约64秒、小队累计生命承伤583。后期存在低血与倒地；累计伤害可能因休整/复活超过开局生命总和。初期过高配置曾使第8关或Boss阶段全灭，之后按基础攻击和后期系数独立校准，未用额外金币/HP跳过。

## 本轮排查

卡片式选关替换后，旧断言查找节点可见文本“已通关”已改为查可访问状态。WebKit图片尺寸采用SVG声明与解码判断；竖屏测试等待resize事件。回归还发现普攻短锁定窗口会吞技能点击，修复为短缓冲并加入规则回归。部分排查证据保留在artifacts/diagnostics。
