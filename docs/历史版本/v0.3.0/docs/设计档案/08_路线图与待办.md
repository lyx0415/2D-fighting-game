## 下一轮优先级

1. P1：真人试玩和手机真机，收集明确的移动/目标/切换/技能/拥挤反馈；Android Chrome、iPhone Safari与FPS/发热还未测试。
2. P1：体验节奏。v0.3模拟整章约12分钟（旧版约349秒），15～25分钟人类首玩目标未验证；优先有效事件、关卡构图与组合机制，不靠等待拖时长。
3. P1：营地信息可读性与装备处理效率。背包变大后检查筛选、比较和触控表现；新增便利功能须沿用装备归属约束。
4. P2：更细腻的职业动作、技能特效、音效层次；当前是具象简美术、整体变换动画与程序合成音效。
5. P2：技能升级/天赋/加点独立设计后实施；先明确消耗来源及与现有成长关系。
6. P2：第二章寒铁王城内容；当前仅有主线线索，尚无第二章实际关卡。

## 持续工程要求

每次同步设计、更新日志、交接和素材清单。运行真源仍为art.ts；不让导出图和运行图成为不一致双真源。生产变更需构建并实际开战；报告按版本和日期另存。完整鼠标流程较慢，必要时运行npm run test:chapter；不把特定算法通关等同真人体验认可。
