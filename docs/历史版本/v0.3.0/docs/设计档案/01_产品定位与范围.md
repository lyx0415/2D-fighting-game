# 产品定位与范围

《灰烬誓约 / ASHEN OATH》是电脑、手机浏览器通用的暗黑奇幻单机小队闯关游戏。侧面人物、横向卷轴，地面可上下左右走动，没有跳跃、重力或高低差。

## 已确认的选择

- 鼠标或手指点按完成全部流程，不依赖键盘、摇杆。
- 最多四人，一人主动控制，其余AI自动普攻与放技能；战斗中点头像随时切换。
- 主动角色点地面移动、点怪锁定，自动普攻，两个一键CD技能，没有蓝条。
- 轻度操作，前两关宽容，Boss清晰预警，移动与技能时机有价值。
- 暗黑奇幻具象简美术，职业与怪物可辨；精细原画、逐帧动画后续提高。
- 营救被囚公主为主线，沿途招募同伴，最多五选四。
- 首版三个完整短关，养成先做经验、三槽装备、金币强化。

循环：剧情线索→营地编队→分段战斗→招募/掉落→通关结算→强化→新关/Boss→更换阵容重玩。

## 范围与成功标准

v0.2.0已扩展为第一章1-1至1-10、31战区、五职业十技能、十类敌人、三品质装备、等级上限10。正常奖励可完成全章，不强迫刷关；第三关前四人、第三关通关后五人，刷新保留已结算进度。

后续三章每章10关。自由加点、天赋、技能升级、法宝、紫金红装备、第二三章20关、联机、账号、云同步、安装包和商业发布尚未实现。

首次15～25分钟（含剧情营地）是未验证目标；旧三关自动点按约105秒；当前v0.3十关模拟约12分钟，不能据此宣称达到时长、最终平衡或真人体验目标。

用户随后授权持续扩充可玩内容，v0.2.0已落实第一章十关。历史首版三关决策保留，用于理解迭代顺序，不代表当前仍限三关。

v0.3.0按用户反馈优先加长每节、增多增强小兵、明确地图边界，重绘英雄并改整章连线舆图与蓝黑旧金UI。游戏主线和10级/三槽成长边界不变。
