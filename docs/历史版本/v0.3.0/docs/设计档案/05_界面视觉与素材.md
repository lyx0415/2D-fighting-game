# 界面、视觉与素材

## 页面分布

标题（继续/新游戏覆盖确认/声音）；三幅可跳过序章；营地（远征地图/同伴编队/装备工坊）；出战准备（四人/队长/提示）；战斗（头像血条/波次/暂停/两技能）；结算（金币经验/装备/新伙伴/首通）。

手机横屏、安全区域、实际触控区至少48 CSS像素；竖屏提示并暂停，旋回后手动继续。目标圈/主动光圈/CD/预警必须辨认清楚，伤害数字限量，品质同时用颜色和文字。中文系统字体优先，不依赖外部字体。

## 统一美术

灰绿、冷铁灰与旧金，低饱和背景、深轮廓和金属亮面。职业通过剑弓杖盾双刃区分；敌祭司暗红，狼四足，Boss宽肩重甲、角冠双链。当前英雄256×320、脚底(128,300)，敌人128×160、脚底(64,150)，右朝向、左向镜像，透明底。现有五动作是代码变换，并非逐帧原画。

地图1920×720，天空月光→远景→建筑树木→雾→碎石地面→前景草丛。战斗通道y360～620，装饰不作隐形障碍，前景不遮预警与血条。

音效来自src/game/audio.ts本地合成，覆盖点击、攻击、箭、法术、受击、掉落、死亡、胜败；首次交互解锁，可调音量。无录音音频包、配音或背景音乐，不把空音频目录写成成品。

## 素材工作流

见../../素材库/README.md、00_规范/统一美术规范.md与catalog.json。人物、装备、地图背景、物体、UI、剧情、音效分类。每项记录ID、来源、状态、文件位置和SHA-256。

运行源当前仍是src/game/art.ts；素材库是同源导出与参考归档。修改导出图不等于修改运行源，除非一起迁移加载。装备裁切含手部衣物，须标成参考；截图是运行参考，不是可直接拼UI的切图。每次更新日志记录素材是否已接入。

## v0.1.1已接入更新

7张独立装备图标已用于装备槽和行囊；旧裁切仍保留参考状态。护盾增加包围轮廓，掉落光点飞向主动角色，近战命中和技能提供颜色反馈。漂字最多30对象、环形特效最多24对象并循环复用；暂停时冻结这些补间和角色摆动。结算显示实际模拟战斗用时。素材库共44项。

## v0.2.0十关版本

地图扩至十关并分三段提示：集结同伴、钟楼与回廊、地下与圣殿。新增5份运行艺术：狂信徒、怨灵、主教人物，以及修道院玫瑰窗/钟楼、墓道拱门/遗骨/烛火两个场景主题；均与原冷铁灰和旧金统一。素材库含50项（其中15人物、5地图、7界面截图）。新主题仍由art.ts生成，并同源导出归档。

## v0.3.0五项反馈落实

整章不再用关卡卡片网格：一张蓝黑地形舆图有10个按钮节点和9条连接；最终Boss节点78px大于普通48px节点。已通/当前/锁定同时用状态色、图形与aria标签表达，小屏横向查看，点击仍进入出战准备。地图包含同章森林、村庄、堡垒、回廊和圣殿细节。

UI主色蓝黑、旧金边饰；中文采用本机中宋/宋体回退，英文Palatino/Georgia衬线铭文风。不宣称安装了新字体。标题、营地、装备、弹窗与战斗HUD整体统一。

五英雄v003形象明确差异，新增十个职业技能图形、战术标签和颜色；各职业原本独立的HP/攻击/护甲/技能范围与CD仍保留，不虚构额外元素克制。战场使用高分辨率矢量纹理，未制作逐帧动作。

石道格纹、金线、边缘路灯和暗化路外定义可走区域；路外移动命令会给出提示。旧50项素材保留历史，新图标和界面版本独立记录。
