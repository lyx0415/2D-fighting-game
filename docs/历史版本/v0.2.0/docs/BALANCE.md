## 测试意义和边界

规则测试采用固定种子42以及7、128、2026，从新存档顺序通关，每关前使用正常获得的装备换装，并以赚取的金币强化武器。控制策略每0.1秒选择附近目标、使用可用技能并躲避预警，其他队友使用实际AI，不注入伤害、生命、装备或奖励。

种子42纯模拟时间为27/31/44秒，总102秒。此结果证明基础数值允许不刷关通关，不能代表人类难度与首玩时长。当前整体偏宽容；15～25分钟首玩目标未验证，后续优先通过有意义的波次与探索内容扩充，不用强制等待拉长时长。

测试数值仍是第一轮起点。最终平衡需要真实玩家操作、不同手机帧率和视觉反馈共同评估。
