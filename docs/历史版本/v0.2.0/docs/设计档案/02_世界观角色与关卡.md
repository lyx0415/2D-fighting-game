# 世界观、角色与当前关卡

黑潮侵蚀王国，公主艾莉娅携带可重启封印的王印离开王城，却被教团掳走。幸存骑士雷恩循囚车痕迹追赶。主题为守护、失守后的誓言与重建信任，战斗必须承载线索推进。

序章三图：公主与王印→教团袭击与边境焦土→雷恩拾剑追赶。文字由页面绘制，可跳过，不影响解锁。
