# 英雄美术 v004：分层有限帧姿态

更新日期：2026-10-30。源码：`src/game/hero-art.ts`。v003原件由父任务归档保留；本版延续精细矢量材质，新增脸型分化和可由运行时选择的部位姿态。

## API与坐标

```ts
export type HeroPose = 'idle' | 'move' | 'attack' | 'skill0' | 'skill1' | 'hit' | 'dead';
export const HERO_POSE_FRAMES: Record<HeroPose, number>;
heroSvg(kind: string, pose: HeroPose = 'idle', frame = 0): string;
```

`kind`支持warrior、archer、mage、tank、assassin，未知值回退战士。未知运行时pose回退idle；frame按该姿态帧数循环，负数可循环，非有限数回退0。

画布256×320、透明底、右朝向，地面锚点保持(128,300)，镜像与位置由运行时负责。帧数：idle 1、move 4、attack 3、skill0 3、skill1 3、hit 1、dead 1；每职业16帧，共80帧。

## 真正分组的部件

SVG使用`data-part`标记：cape、backAccessory、rearLeg、frontLeg、skirt、body、rearArm、frontArm、weaponRear、weaponFront、head、ground-shadow；部件不存在时不生成空组。upper-body维护躯干与手臂/头部的共同连接，头、两腿、两臂与武器仍有独立变换。

移动帧左右腿独立交替、足部交替抬起，披风/袍摆与持械手有不同摆幅；攻击在肩部支点改变持械臂姿态，头部和重心配合。弓弦拉点和箭尾根据蓄力/释放实际改变几何形状。两个技能使用不同的关节参数和武器姿态；法师施法手另有可辨识光点。不是对整张静态图统一旋转、平移来模拟全部动作。

倒地包含折叠手臂、武器与腿部姿态，另将横向跌倒构图缩放到固定图集格内，避免尸体武器裁切；它仍是单张有限姿态，不是物理布娃娃。

## 职业动作语言

| 职业 | 移动 | 普攻 | 小技能 | 大技能 |
|---|---|---|---|---|
| 战士 | 大幅阔步，持剑手与披风配重 | 蓄力后向前下方斩击 | 更大幅横扫 | 收臂举刃防护架势 |
| 坦克 | 小幅重步，盾基本稳固 | 独立锤臂大幅挥击 | 盾臂向前上方震击 | 抬盾遮护躯干和面部，锤稳定 |
| 射手 | 轻步，弓稳、拉弦手摆幅独立 | 拉弦、释放、回位 | 连续快速拉弦与箭尾位置变化 | 双臂上举，弓箭朝向上方散射 |
| 法师 | 缓步，袍摆与靴独立，法杖轻摆 | 点杖与另一只手配合 | 寒霜手势向前，掌心光点 | 空手高举、法杖调整，与陨火呼应 |
| 刺客 | 最快最宽步幅、上身前倾 | 两臂反向错开刺击 | 更低重心前倾、前刃刺向前下 | 双刃交叉合击与回收姿态 |

## 已验证与边界

- Node24动态导入并生成全部80帧。
- Python XML解析全部80帧，viewBox/尺寸保持256×320，存在可识别部位分组。
- Edge/Chromium渲染全姿态图；单独以透明画布扩出四周200像素，检查原SVG范围之外的可见像素。80帧在alpha>48的可辨像素范围均未越出256×320；极淡柔光可落在边缘，此检查不把alpha≈0的柔光当作实体裁切。
- 对明显越界的刺客刀刃、法师举杖、坦克举盾和倒地构图作了定向修正。
- 独立TypeScript类型检查通过（以子任务实际运行结果为准）。

预览缓存位于`.cache/hero-v004/`，含all-poses.png、summary.png、每帧SVG和透明扩边检查图。缓存不作为运行真源。

本版是可编辑SVG的**有限帧部位姿态**，没有宣称骨骼绑定、蒙皮、连续骨骼动画或手绘逐帧成片。场景已由hero-motion.ts按模拟时间采帧、scene.ts预载纹理并接入；CD与伤害规则沿用既有系统，当前验证见TEST_REPORT.md，素材清单与图鉴由脚本同源导出。

## 透明边缘严格复核

集成回归中alpha>12的画布边缘检查发现Chromium法师move第2帧的月冠顶部两个像素触边；WebKit原先无触边。仅将该帧上半身上下浮动从-3改为-0.5逻辑像素，为冠饰留2.5像素额外余量，腿部、脚底、其他帧及接口均不变。随后用相同的边缘alpha>12规则独立复核两引擎80帧，最终集成复核见artifacts/browser-v0.4.0-2026-10-30.json。
