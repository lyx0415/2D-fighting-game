# 英雄美术 v007：暗黑中世纪重绘

2026-10-30。本轮根据用户对面容与动作的否定反馈，重新处理人物比例、面部体积、服装材质与动作节奏。源文件为src/game/hero-art.ts，运行层、全身图与独立头像共用同一几何。

## 重绘方向

参考Blizzard的[Diablo IV角色美术说明](https://news.blizzard.com/en-us/article/23665024/diablo-iv-quarterly-updatejune-2021)和Bandai Namco的[流浪骑士职业参考](https://en.bandainamcoent.eu/elden-ring/elden-ring/characters/vagabond)，吸收材质分层、低饱和服装和清晰大形体的表现原则。没有复制参考人物造型、商标或贴图。五名英雄的身份和职业武器延续本项目原创设定。

旧版头部与身躯比例偏大、面部多边形和眼白对比过强。本版用更小头部、更连续的颧颌曲线、窄眼睑与自然嘴线重新构造，鼻部主要依靠软渐变与少量轮廓，去掉夸张下唇、笑纹和面部碎片高光。头部围绕颈根缩小，披风/头发与衣领保持重叠。当前为风格化成熟比例，不声称达到写实人体比例或3D建模。

| 职业 | 形象与材质 |
|---|---|
| 战士 | 宽颌短发、旧钢半盔、胡茬与小伤痕；暗酒红十字战袍、旧皮带与钢甲 |
| 射手 | 柔和女性面容、暖棕发辫、暗绿兜帽；毛皮护肩、皮质斜带与行囊 |
| 法师 | 冷峻四分之三面容、灰银长发、压低亮度的冠饰；炭灰蓝叠领与长袍 |
| 坦克 | 正面宽厚老兵脸、灰须、厚盔；毛皮护领、深钢甲与磨损盾面 |
| 刺客 | 窄脸、暗发、灰紫面罩；层叠遮肩与暗皮腰带，保持敏捷剪影 |

角色保留front、threeQuarter、profile三角度头像。默认坦克为正面，其余为四分之三；这是静态朝向差异，未增加实时转头系统。

## 动作变化

降低待机蹲伏和躯干过度前倾；行走步幅、抬脚高度和上下起伏收敛，重甲步伐更沉，射手/刺客仍相对轻快。攻击动作保留蓄势、发力、随动、回收，延长打出后的随动区间；剑锤与短刃不再在峰值后立即回到初始角度。

保持肩肘/髋膝IK和父子武器层级，不改变伤害、技能CD或行动锁。人物仍为二维刚性关节，而非3D蒙皮；动作自然度需要实际观看与用户确认。

## 接口与验证边界

heroRig仍为五英雄93层，256×320画布，脚底(128,300)；heroSvg提供80个离散样本。heroPortraitSvg仍128×144声明尺寸，viewBox为94 32 66 88，适应缩小后的面部。headArt的变换同时作用于运行头和导出头像，避免两个不一致真源。

本子任务已实际执行TypeScript检查；运行截图、80样本透明边缘、生产开战及最终素材导出由主任务统一验收，并记录到本版测试报告。此处不预先宣称视觉、真机或动作验收通过。
