# 英雄美术 v005：程序化部位关节动画

更新日期：2026-10-30。运行几何、静态预览与运动真源在`src/game/hero-art.ts`；`src/game/hero-rig.ts`提供约定的连续rig入口，单向再导出，不形成循环依赖。共享结构位于`rig-types.ts`。

## 公开接口

```ts
heroRig(kind: string): RigDefinition;
heroRigMotion(kind: string, pose: RigPose, phase: number): RigTransform;
heroSvg(kind: string, pose: HeroPose = 'idle', frame = 0): string;
```

画布256×320，脚底(128,300)，右朝向。五职业仍为warrior、archer、mage、tank、assassin；未知职业回退战士。idle/move的phase按0～1循环，attack/skill0/skill1/hit/dead按单次0～1进度，非有限数回退0。`heroRig`缓存返回只读使用的定义；运行端应修改场景节点，不修改共享定义。

`heroSvg`兼容原API，`HERO_POSE_FRAMES`仍为idle1/move4/attack3/skill0三帧/skill1三帧/hit1/dead1，共每人16、全体80个静态采样；采样由同一rig和连续运动矩阵合成，不维护第二套姿态图。

## 关节与部位结构

- pelvis：髋部承重根；torso：躯干关节；breastplate：实际胸甲/衣物层。
- frontThigh/rearThigh → frontShin/rearShin → frontFoot/rearFoot：髋→膝→踝→足。
- frontUpperArm/rearUpperArm → frontForearm/rearForearm → frontHand/rearHand → frontWeapon/rearWeapon：肩→肘→腕→持械物。
- head、cape、skirt、backAccessory：头、披风/袍摆与背负物。

每个RigPart为256×320原坐标透明SVG，pivotX/Y是原图的关节点，parent为关节父层。数组保证父层先于子层。武器严格属于手，手属于前臂，不能在手臂弯曲时单独留在世界坐标中。空的pelvis/torso层是变换节点，不是缺失素材。

原始衣甲图形按肘、腕、膝、踝方向的重叠半平面分层，关节点加同材质圆面掩接，保留纹样/护甲/皮革，避免分段运动出现硬断口。角色没有共享一套脸型或完整人体大图旋转。

## 连续运动方法

步态采用足部支撑期与摆动期：支撑期足部向后移动以抵消角色前进，摆动期使用连续曲线前摆并抬脚。髋膝与肩肘采用带柔性接近最大臂展的两节逆向求解，关节角按连续phase返回；足部反向补偿保持着地面方向，髋部有小幅承重起伏。攻击和技能使用预备→发力→随动→回收曲线，不依赖有限几帧播放来获得连续运动。

不同职业的步幅、抬脚、重心、上身倾斜和手臂摆幅独立：战士稳健、坦克重步、射手轻步、法师袍下缓步、刺客低姿快步。待机也有独立站姿：战士前后站稳持剑；坦克宽站护盾；射手倚重后足持弓；法师直立稳杖；刺客屈膝前倾。待机呼吸和布料摆动为连续低幅曲线。

战士/坦克斩击和锤击通过肩肘合拢、手腕和武器随动完成；弓手保持持弓臂稳定、另一只手拉弦，上举动作改变两条手臂；法师长杖保持平衡，另一只手完成寒霜/陨火手势；刺客双手有不同刺击、低姿和交叉方向。手腕增量限制在合理范围，长杖倒地撑持允许更大的受控转角。

倒地是髋部下降、膝部折叠、上身前倾和手臂收拢的连续过程，不是整张角色图横转。长袍下摆在倒地时保留地面高度，长杖提前收向身体以避免穿出画布。没有物理布娃娃或碰撞骨架。

## 面部与历史感

## 验证与限制

子任务进行独立TypeScript检查、静态SVG/XML检查、父子关节拓扑与连续运动数值检查；浏览器还采样每个pose的21个phase（5×7×21=735组）检查256×320边缘alpha>12是否有可见裁切。针对连续挥击中间帧、长杖与倒地袍摆作定向修正。

预览与检查缓存位于`.cache/hero-v005/`，summary.png为关键阶段，animated.html为可切换姿态的连续关节预览；缓存不是运行资产真源。父任务负责实际场景、姿态切换插值、敌人/技能时序、性能和整局游戏验收。

实事求是称为**程序化部位关节动画**：有父子关节、两节求解、连续曲线；没有顶点蒙皮、商业骨骼编辑器绑定或手绘逐帧成片。原SVG图形仍按刚性部位运动，不能宣称无限自然的软组织变形。
