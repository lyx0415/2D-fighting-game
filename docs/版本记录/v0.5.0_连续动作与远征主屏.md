# v0.5.0：连续动作、战斗反馈与远征主屏

日期2026-10-30。回应四项反馈，保留第一章十关、数值成长、招募和本地存档规则。

## 连续关节与动作衔接

五英雄使用93层，十类敌人126层，合计219个运行部位层。肩→肘→腕→手持物、髋→膝→踝→足为父子关系，英雄以足部支撑/摆动和双节IK求解步态，并配合承重起伏。攻击/施法使用准备、发力、随动和回收曲线。新姿态以约0.11秒smoothstep过渡，同姿态直接实时求值，避免持续低通拖慢脚步。

战士阔步横斩、坦克护盾重步与挥锤、射手轻步拉弦与上举散射、法师稳杖/袍摆/手势、刺客屈膝快步与双刃刺击。敌人有尸兵蹒跚、腐狼四足扑咬、弩手射击、祭司/怨灵施法、精英重击/盾冲及Boss动作。倒地采用关节收拢和重心下降。暂停冻结动作；朝左时根位移/旋转与形象一起镜像。

`heroSvg`保留原API，但80图仅为同源连续动作采样；运行直接驱动Phaser关节，不依赖低帧贴图切换。此为程序化刚性部位动画，有关节与IK；不宣称顶点蒙皮、物理布娃娃、脚底碰撞锁定或真人运动审美已经验收。

## 面部、服饰与站姿

在独立脸型上强化眉骨、眼窝、鼻梁鼻翼、嘴角、下颌刻线；战士有旧伤浅疤，坦克有年龄纹和宽厚胡须，射手有柔和五官/淡雀斑，法师有疲倦轮廓/符印，刺客有锐眼和细疤。站姿区分稳剑、重盾、后足持弓、直立稳杖、低姿双刃。十类敌人也更新面容、材质和职业轮廓；精英与Boss保持独立头冠、重甲和武器，不仅换色。

## 声音、命中与特效

33种本地合成配方区分五类英雄普攻、敌方爪咬/弩/吟唱/重击、十个职业技能，以及金属、肉体、箭、冰、火与魔法命中。噪声、谐音层、滑音、时长和包络不同；按音色节流而非所有事件统一节流，最多24个短音并发。首次用户交互启用，音量可调或静音，结束节点断开连接。

斩弧/双刃/爪痕、箭迹/连射/箭雨、护盾纹、冰晶、火星、暗影和受击碎屑区分动作来源。最多64组瞬态特效，使用模拟时钟，暂停冻结。伤害事件携带来源职业、目标类型和技能索引；技能区分施放、预示与命中，投射物传递同一信息，避免在预示阶段提前播放陨火爆裂。

Chromium已对33种音效用同一合成函数离线渲染WAV，检查非静音波形、不同指纹和无削波。当前Windows Playwright WebKit没有AudioContext/OfflineAudioContext及其前缀版本，其音频渲染明确跳过；其他交互仍验证。Safari真机音频需另测。

## 页面主次

移除左侧常驻三栏目。地图成为远征主屏，底部出战队列和大启程按钮突出战斗目标；战斗配置、装备仓库、英雄成长从次级入口展开为可收起面板，底部入口保持可用。装备格和筛选保留，成长仅展示真实等级/经验/职业专长，天赋明确为后续开放。

桌面与手机横屏分别控制辅助信息密度。地图背景、路线和节点统一投影，修复宽屏下图形留白引发的连线错位；自动化比较路线起点与按钮中心。短屏保留地图横向查看和48像素关卡触控区。

## 素材与维护

v0.4.0的166项清单与对应图像完整保留`素材库/99_历史版本/v0.4.0/`，附源码采样；历史采样不是独立可运行旧项目。新增v005人物采样、219部位SVG与15份parent/pivot清单、连续动作离线图鉴、33份同配方WAV试听，以及远征/整备/战斗参考截图。素材总数含历史参考、图层和音效，不等于游戏角色数量。

运行入口仍为`art.ts`，几何分别委托`hero-art.ts`与`enemy-art.ts`；场景在`scene.ts`、关节在`rig-renderer.ts`、音色在`audio-cues.ts`、效果在`combat-effects.ts`、新主屏在`campaign-hub.css`。不直接修改导出图片代替改源。
