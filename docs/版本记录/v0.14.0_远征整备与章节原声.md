# v0.14.0 远征整备与章节原声

2026-11-19。延续第一章十关、五职业和版本 1 存档。

## 远征整备

- 灰烬地带使用新远景插画，其余主题使用各自的关卡画面。出征单与章节入场共享封面选择。
- 出征单统一显示契约、上次星徽与最快纪录、基础通关奖励、出战队伍、领队和战术提示。敌情可以展开，与远征纪事共用敌军图鉴。
- 可从出征单打开工坊或英雄修习，默认选当前领队。使用「返回出征整备」保留关卡、契约及已提交的整备变化。新关默认使用誓约之路。
- 战斗远景使用较慢的横移视差。余烬和雾带限定在可行走范围上方，地面命中范围与单位判定沿用原规则。

## 章节原声与混音

- 《余火行路》由低弦和拨弦构成，24 秒基础循环。Web Audio 共享时钟起播，在遭遇和首领战增加同拍低鼓和断奏。HTML Audio 后备播放同一基础曲，按场景调整响度。
- 典狱长和黑潮主教各有独立的预警与落地采样。危险音优先于常规战斗声，暂时压低配乐。原职业录音保留，普攻及通用受击音量进一步降低。
- 旅途设置可独立调整总音量、音乐、环境、战斗与界面、人声。暂停菜单可进入设置，关闭设置回到暂停界面。快捷静音再次开启时恢复上次总音量。旧存档缺少新设置字段时使用默认值。
- 新音乐与四条音效均为项目原创程序化渲染，由 `python scripts/build-audio-v014.py` 重建。来源与 SHA-256 见运行素材 manifest，旧录音署名见项目许可。

## 美术来源

灰烬边境主图使用内置 imagegen 生成，保留完整画面比例，等比缩至 1536×768 并输出 WebP。暗色蒙层由 CSS 绘制。运行真源在 `public/assets/v014/ashen-border.webp`，分类导出与试听见 [v0.14 素材图鉴](../../素材库/远征整备与原声v014.html)。
