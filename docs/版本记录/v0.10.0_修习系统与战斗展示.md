# v0.10.0 修习系统与战斗展示

2026-10-31。针对普攻过吵、技能缺乏特性、背景建筑侵入走道、人物过大和缺少主动成长的反馈。

## 实际实现

- 普攻出手增益0.65→0.15，普通命中0.65→0.12（分别约-12.7dB、-14.7dB，均在玩家主音量之前）。技能0.57、发力0.30、受击0.15、界面0.42；普通声部最多5个同时播放，总声部上限18；分组间隔限制连续叠加。HTMLAudio后备也保留分类增益，调整主音量不会把普攻恢复成高音量。
- 17项技能/命中WAV重制：剑刃破空、木弦连射/箭雨、冰裂、陨火蓄力与生效爆发、重盾与低频誓言、暗影与短刃切入。技能文件长约0.72～2.46秒；陨火Cast不再预先爆炸，0.7秒后由命中事件触发fireHit。原6环境循环继承。
- 5种职业发力声仅在成功施法时触发；同cue至少4秒，全队发力间隔至少1.4秒。使用本机Huihui/Zira SAPI离线合成、修剪、变调，非真人表演或外部演员素材。没有把语音合成当作真人录音。
- 建筑背景收束到y350，路缘与灯点明确标出y360～620可走带。新增内置image_gen生成的独立石道纹理，按原生比例截取260像素带、随世界坐标铺设；五主题独立调色，建筑像素不进入脚下层。边缘物件移到边界外。保留矩形通道，无建筑内部寻路。
- 英雄显示比例0.265→0.225，再缩小约15.1%；普通敌人0.21、狼0.19、Boss0.35，配套缩小阴影、脚圈、护盾轮廓与点选判定。普攻/技能射程和地面碰撞保持原规则。
- 营地英雄成长开放天赋与战技修习，自动保存；战斗读取修习快照，战斗中无法加点或洗点。详见长期设计04章节。

## 成长规则

等级每升一级获得1天赋点，总预算level−1；坚韧每点+职业初始生命5%（合计四舍五入）、锋芒每点+2攻击、铁壁每点+2护甲，各上限5点。10级共9点，不能全满。

2/4/6/8/10级各获得1技能点，总预算floor(level/2)；两个技能各可追加3点，等级1→4。每点使伤害/护盾/自身减伤效力+8%、基础CD缩短4%，线性累计。射程、控制、持续时间不变。坦克减伤从40%最高到49.6%；战士护盾从最大生命30%最高到37.2%。10级共5点，不能同时点满两个技能。

营地免费重置当前角色，返还全部预算，不改变金币、装备、经验。预算由等级减去已分配值计算，没有可重复领取的奖励计数器。旧SaveData.version=1沿用，可选talents和skillRanks缺省为0；现有等级立即提供未分配点数，不丢旧资产。新伙伴按原规则继承等级，分配为空。非法结构、超支或超过上限的档案拒绝读取并优先恢复有效备份。
