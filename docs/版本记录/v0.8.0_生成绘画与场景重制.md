# v0.8.0 生成绘画与场景重制

2026-10-31。用户再次否定代码绘制的人物与空旷道路，明确授权使用GPT Images绘图并插入游戏。本版实际迁移人物和环境渲染路径，不沿用v007矢量作为审美已认可结果。

## 运行素材

使用内置image_gen，不需要API密钥。五英雄分别生成4×3透明动作图集，另生成敌方、环境物件、五种战斗背景与章节地貌。战士做了一次同身份图集边界修订。原PNG、完整提示词、来源和修订说明在素材库/08_生成原稿/v008；未下载外部游戏角色、GitHub美术包或插件。

共18张运行WebP：5英雄图集、5立绘、1敌方图集、1物件图集、5战斗场景、1章节图。英雄共60姿态；敌方图集为10类形象和2个Boss施法变体；物件8格，合计80格。动作图集为512×512透明格，脚底(256,480)。全部随生产构建本地打包，无运行外链。

## 人物与动作

人物采用有材质、明暗和成人比例的绘画形象。战士暗红甲袍和剑、射手绿兜帽皮革与弓、法师银发深袍与杖、坦克灰须重甲盾锤、刺客紫黑轻甲双刃。界面立绘与战斗来自同一图集待机格。

PaintedCharacter使用模拟时钟/步行距离选取待机、四步行格、蓄势/攻击、小技能、大技能、受击和倒地图；暂停冻结。原伤害、CD、锁定和操作锁不改。敌方普通单位目前为绘制基形配合移动、起伏和攻击前倾；两个Boss增加施法变体。尚不是为每一类敌人绘制完整步行/攻击帧，不将12格敌方图写成12种敌人或完整敌人动画。

图集自动打包只做分格、相邻碎片清理、透明边距、缩放和格式转换；没有用代码重画脸型和身形。生成姿态之间仍可能有细节差异，当前帧数有限，真人动作自然度与审美要继续验收。

## 地图与场景

焦土村庄、雾林、监牢、修道院、墓道分别使用完整绘制场景；远处建筑、地形、光源与近处碎石/植被形成纵深。移除覆盖地面的重复矩形砖路，仅保留低对比金线和灯点，保持FLOOR y360～620与碰撞一致。打包时将绘制地面纵向对应到这一范围，建筑与物件作为装饰，不新增隐形碰撞。

新增独立推车、火盆、祭坛、枯树、桶箱、墓碑、岩石蕨类、营帐图集，按主题和战区变化放在道路两侧。背景仍使用横向平移和周期性平铺，边缘可能看出循环；尚未制作每个战区独立长卷或真实三维遮挡。

章节舆图换成绘制的山谷、河桥、森林、堡垒、修道院和圣殿全景，10个HTML节点、路线、拖动、浏览与当前定位继续工作。标题及序章背景也使用绘制场景；剧情文字保留，未新增三张专门的公主剧情插画。

## 源文件与保存

统一入口仍是src/game/art.ts，转出raster-art.ts的本地资源地址；实际位图真源是public/assets/v008及manifest.json。scene.ts与painted-character.ts负责绘制和帧播放。旧hero-art、enemy-art、chapterAtlasSvg等保留作历史、离线对照和旧测试，不作为当前战斗人物或地图背景。

art:pack使用scripts/prepare-painted-assets.py；assets:export使用export-painted-assets.mjs。只改素材库副本不会更新运行纹理，须同步public源和manifest。旧源码、清单与测试报告保存在artifacts/v007-before-v008，既有v007和更早资源文件保留，未覆盖。

实际测试、清单和限制见[测试报告](../TEST_REPORT.md)和[阶段交接](../进度交接/2026-10-31_v0.8.0_绘制美术与场景交接.md)。
