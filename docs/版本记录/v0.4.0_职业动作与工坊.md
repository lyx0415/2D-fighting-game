# v0.4.0：职业面容、动作、技能徽印与装备工坊

日期：2026-10-30。对应用户四项反馈，在第一章十关可玩版本上迭代；角色成长、经济、招募顺序与旧存档结构保持兼容。

## 角色面容与动作

五名英雄沿用已建立的服饰、发型、武器与配色，但重新区分脸部轮廓：战士方颌、宽眉骨；坦克更宽厚的老将面孔与白胡须；刺客收窄脸部和尖颌；射手柔和椭圆面容；法师修长面型与深肤银发。详见[英雄美术v004](../英雄美术v004.md)。

英雄源图拆分头、躯干、双腿、双臂、前后武器、披风和袍摆。每职业16帧：待机1、行走4、普攻3、小技能3、大技能3、受击1、倒地1，共80帧。战士阔步横斩，坦克重步挥锤举盾，射手拉弦与上举散射，法师袍摆/手势/举杖，刺客前倾快步与双刃交叉。弓弦与箭尾随帧改变几何。采用有限帧矢量姿态，不宣称骨骼动画或手绘逐帧动画。

`hero-art.ts`为造型与姿态真源；`hero-motion.ts`根据战斗模拟时间选择帧；`scene.ts`预载纹理并播放。`Unit.action`记录普通攻击或技能索引的表现窗口，不增加原有伤害、CD或操作锁定。移动优先展示行走，倒地优先展示倒地，暂停冻结模拟时间和动作。

## 双技能区

右下角采用小技能铭牌与稍大的大技能徽印，两者有独立职业图形、铭文、战术标签和边框。战士钢刃、射手风羽、法师寒星、坦克重盾、刺客鸦影采用不同轮廓和色调；切人同步更新，无需重新开战。

技能区考虑横屏拇指触达和安全边距，实际按钮尺寸大于48 CSS像素；手机短屏收紧图形与说明。冷却使用径向遮罩、剩余秒数和按钮禁用，短锁定期间保留原有技能缓冲。UI点击不穿透到战场。

## 装备工坊

直接点击带头像、姓名、职业和等级的角色栏，替代下拉选择。当前角色以金边和标记突出。桌面三栏分别为角色与三个已装备槽、集中仓库、当前选中装备详情；小屏改为两栏或单栏，仓库在固定高度区域内部滚动。

仓库用方格显示图标、品质文字、强化等级与佩戴者。筛选按部位、品质、穿戴状态组合，并可限制为当前角色可用；提供重置按钮。点击格子查看属性、与当前槽位的差值，以及装备/强化/出售操作。筛选与角色切换不消耗资源。点击已装备槽会清除筛选并选中该物品。

装备必须先从原佩戴者卸下才能转交；职业限制、强化上限与价格、金币不足拦截、已装备不可出售仍由原成长规则控制。替换下来的装备留在仓库。界面操作后即时保存；筛选和选中物品只是本次界面状态，不写入存档。
