# v0.13.0 发布前代码审查

2026-11-06。复查存档校验、导入恢复、安装反馈及构建依赖。

| 发现 | 影响与修订 |
|---|---|
| 相同进度重复保存会轮换备份 | 跳过字节一致的写入，保留上一份有效进度。档案页新增恢复入口，显示同伴、通关数与金币，再由玩家确认。当前有效进度会交换到备份，可再次恢复。 |
| 导入可收到空角色、无效职业关联或未知封装版本 | 统一拒绝错误格式。保留旧版原始存档与 UTF-8 BOM 兼容，按 UTF-8 字节限制文件体积。 |
| 文件读取完成时原弹窗可能已经关闭 | 只有原输入仍连接且文件仍是当前选择时才展示确认。失败时允许重新选择同一文件。 |
| 安装弹窗取消后显示安装成功 | 按安装选择区分接受与取消，提示不可用时给出浏览器菜单指引。 |
| 开发依赖存在已知漏洞 | 锁定 Vite 7.3.7 与 Vitest 4.1.12，完整 npm 官方审计复核为 0 项。运行依赖审计也为 0 项。 |

受影响的测试工具版本范围见 [Vitest 安全公告](https://github.com/advisories/GHSA-82fw-gwwq-j7x9) 和 [Tinypool 安全公告](https://github.com/advisories/GHSA-5gmw-xhrv-c9v3)。审计针对本次锁文件及当时的已知公告。

恢复可在标题页的“进度管理”中操作。无有效备份时入口置灰。误恢复后可再次打开档案页找回被替换的进度。恢复不跨浏览器账户或域名，跨设备仍用 JSON 导出和导入。

分类素材沿用 v0.13.0 的运行文件和素材库，保留原图及声音来源。恢复确认界面截图归入本轮验收记录。真机安装、设备性能与商店审核仍列为待验收。
