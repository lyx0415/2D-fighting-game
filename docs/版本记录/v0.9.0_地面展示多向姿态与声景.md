# v0.9.0 地面展示、多向姿态与声景

2026-10-31。按用户三项反馈优化已有形象在游戏中的呈现，保留已接受的暗黑中世纪材质与角色身份。

## 地面和尺寸

英雄显示比例0.36→0.265，约缩小26.4%；普通敌人0.30→0.245、狼0.27→0.22、Boss0.50→0.40。命中点按高度对应缩小后的形象，攻击数值/射程/碰撞地面不变。

FLOOR仍为y360～620。可走带轻微提亮，背景与前景更暗，边缘增加低矮石屑与路灯点；不是增加新障碍寻路。人物加场景色调与收小的脚底阴影/主动圈。绘制地面的滚动改为与镜头1:1，取消旧0.45速地面滑动，使人物脚底、路面和路边物件处于同一世界坐标。远景和地面仍为同张绘画，不宣称新做3D地形或真实碰撞建筑。

## 多角度与身体姿态

用内置image_gen对既有五人身份参考生成10格新待战图。首轮仍偏同向侧脸，另做定向修订：法师和坦克正面；射手左侧四分之三；战士右侧四分之三；刺客偏正面警戒。每人另有一格低血量戒备姿态。当前战斗待机使用新图，移动/攻击/施法继续使用v008动作图；界面立绘改用新待战图第一排。

原图、修订图、完整提示词及引用图片路径保存08_生成原稿/v009。prepare-stances-v009.py只分格、清理邻格碎片、透明边距及统一脚底，不用代码重画脸。运行public/assets/v009为6张WebP（1图集、5立绘），manifest记录哈希；旧v008图像不覆盖。

## 声音

使用GitHub开源[jsfxr](https://github.com/grumdrig/jsfxr)离线生成6个魔法层，结合原创物理DSP制作39个音效与6条16秒环境循环。已固定仓库提交62fbd7ab0705a62606fda36f1cb9bde7cabd2080、保存源代码、文件哈希与Unlicense于tools/vendor/jsfxr；运行时不联网，也不依赖该生成器。

五职业区分：战士宽风切与短促钢刃、射手拨弦/木质连射、法师奥术/冰裂/火焰、坦克低频锤击与盾撞、刺客高频短刃与反向耳语。命中区分甲、肉体、箭、冰火和魔法；五种受击呼吸/闷哼质感是合成音，不是录音配音。

营地、焦土、雾林、监牢、修道院、墓道各有环境层，含风、低音铺底、叶响或滴落。声音实际由public/audio/v009的WAV播放，原WebAudio配方仅在文件未就绪/失败时回退。样本预载、限并发、同音色节流与压缩控制重叠；音量变化同时控制环境层，暂停静音环境，回营切换主题。不支持AudioContext时尝试HTMLAudio后备，声音权限仍遵循浏览器用户交互规则。

曾核对Kenney素材，但下载返回网页，未使用其音频；该响应只保留artifacts诊断，不当作素材。最终声音来源为jsfxr与原创DSP，无外部声音包依赖。

每次出战显示章节王印、第一章/关号/名称/一句场景信息与真实美术资源加载进度。视觉资源就绪且经过至少1050ms后进入；慢设备可超过一秒。加载期间战斗暂停，HUD延后显示，不移动或受伤。演出中失焦/竖屏会继续保持暂停，玩家点击继续才恢复；旧回调在回营或重开后失效。
