# v0.11.0 可选声景、分层特效与紧凑整备

2026-10-31。用户要求改善突兀的发力声音、提供更多技能音色候选、精简仓库与天赋界面、升级角色特效、缩小普通单位并突出Boss。源码和生产构建已更新；本记录区分实现与听感/真机边界。

## 声音与可选版本

| 方案 | 发力/技能方向 | 默认状态 |
|---|---|---|
| grounded 沉稳写实 | 呼吸起音、较干燥的材料层、克制空间尾 | 默认 |
| feral 粗砺战吼 | 较粗糙声门、胸腔共鸣与颗粒冲击 | 可选 |
| mystic 秘仪回响 | 较轻气息、共鸣与长空间尾 | 可选 |

每套24音源：10技能施放、7材质/属性命中、5角色发力、2防御持续层，共72WAV。其余28个公共音源（含6场景环境）继承v010，每套实际可用52个文件，三套总计100个不同运行文件。本轮72个均为原创物理/声门DSP；新发力声没有v010的SAPI朗读层，模拟气息和音高起伏，不是真人演员配音。不能把“已生成不同音色”说成已获真人自然度认可。

设置新增三方案切换、发力/攻击/防御/法术试听和独立发力开关，保存在旧v1存档的可选settings.audioProfile/settings.exertions字段。标题与营地齿轮可进入设置。缺省沉稳写实与发力开启；旧档不需要重建。普攻出手/普通命中仍保持0.15/0.12分类增益，不因为换音色恢复嘈杂音量。发力仅主动角色成功施法触发，保留同cue4秒/全队1.4秒节流。

不屈与守护誓言分别新增2秒低频循环样本，循环播放的总时长由实际护盾/减伤状态决定，分别最多6/5模拟秒。破盾、到期、倒地、退出或胜负结束回收；暂停将持续层静音，恢复再继续；切方案取消旧循环及未完成异步加载，下一帧重建当前有效状态。持续层单独低增益0.13，避免盖过技能起手和命中。陨火cast仅蓄力/下坠，命中事件才触发爆发。

素材库的[声景与整备v011图鉴](../../素材库/声景与整备v011.html)以同一cue横向比较三版本，原生音频控件、统一试听音量、持续层循环选项，一次仅播放一条。文件原始音量和游戏混音不同。

## 特效与实战比例

- 特效拆分脚下层、人物前方形状层、加色光粒层，模拟时钟驱动，暂停冻结运动；同时瞬态效果最多64个。
- 战士为多层刃光/火星与随护盾剩余状态消退的护壁；射手为三箭轨迹和目标区分批落箭；法师为目标冰晶/受减速脚圈、0.7秒下坠陨火与命中火焰残留；坦克为盾震冲击/裂纹与厚重多边护层；刺客为位移拖尾、双刃交错与切入火星。真实命中/伤害时间不由特效回响改变。
- 修正箭雨/寒霜起手特效原先偏在施法者处的问题，现以目标位置为中心；地面法阵与空中轨迹分层。
- Boss增加脚下符环、上升微粒、蓄力轮廓与狂怒颜色。裂地攻击生效时携带已锁定shape/length/width/angle，特效沿相同方向展开；圆形技能显示冲击/环状光柱。保留清晰红色预警，预警结束前不新增伤害。
- 大伤害技能及Boss生效触发轻微85ms镜头震动，同类最少间隔0.4秒；没有增加强制停顿、改变技能CD或普通移动速度。
- 显示比例：战士0.185、射手0.18、法师0.178、坦克0.20、刺客0.175；相对旧统一0.225缩小约11～22%。普通小兵0.17、狼0.155，精英保持0.21形成层次；典狱长0.39、主教0.405。阴影、血条/名称、点选区域按实际比例匹配。地图/FLOOR和攻击距离保持逻辑像素规则。
- 典狱长生命3600→4200，主教7600→8000；攻击/护甲/技能间隔未额外提高。主教初试8800导致原未配点通关模拟失败，已回调8000，随后四种子十关基线通过。不是通过削弱普通怪或注入额外资源换取通过。

## 简洁整备

仓库改为固定角色栏、三装备槽、集中滚动方格、侧边详情。减少重复标题和大立绘；高级筛选弹层覆盖方格、选择后可收起；保留部位/品质/归属/职业组合筛选。增加名称/职业搜索（Enter或离开输入框应用）、品质/部位/强化排序；搜索内容转义。装备/强化/出售与归属规则不变，控件可点击高度至少48CSS像素。短横屏各工作区内部滚动，角色栏和整备页入口保留，避免整页反复下拉。

成长页移除加点之前的大段人物传记，角色切换、当前属性、点数、三个天赋和两个技能集中。显示当前等级和下一次修习后的效力/CD，底部免费重置固定可见；点数预算、加成、最高等级与免费重置规则不变。人物传记仍在战斗配置页。

## 验证与边界

实际结果见本轮TEST_REPORT和交接。当前84条规则、双引擎60项完整流程回归通过；图鉴及最终触控尺寸专项另存报告。查看过修习/工坊/护盾/Boss截图；全章模拟不是自然鼠标完整通关。72WAV独立格式、RMS、SHA及6循环接缝检查通过，素材子任务验证重复重建一致。
