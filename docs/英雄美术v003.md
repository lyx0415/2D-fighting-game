# 英雄美术 v003

更新日期：2026-10-30。源码：`src/game/hero-art.ts`。此文件提供项目内原创、可编辑的五职业矢量基形，不引用外部素材或字体。

## 接口与坐标

`heroSvg(kind: string): string` 支持 warrior、archer、mage、tank、assassin；其他值回退战士。输出SVG为256×320，viewBox同尺寸，右朝向，脚底锚点约(128,300)。接入时镜像处理左右方向，originY使用300/320。战场纹理应按256×320加载，不能沿用旧128×160纹理尺寸与缩放值直接叠加。

## 状态与验证边界

这是静态多层SVG，未制作逐帧走路/施法动画，也未实现可独立绑定骨骼的部件结构。运行时仍需用现有变换动画驱动；视觉细节提升不能当作完整动画升级。

父任务负责在`art.ts`统一入口、纹理加载、英雄卡片与战场接入，并更新素材库清单/图鉴/历史版本。本子任务只交付美术模块与本文，不修改其他系统。

## 本次子任务验证

2026-10-30：五份SVG均可由Node24动态导入，Python XML解析通过，尺寸和viewBox均为256×320；实际图形包含40～98条以上路径（含面部细节后更多），无外链。Edge/Chromium已渲染五人并列预览，检查武器与脚底完整、职业配色和头饰差异；缩略图仍待父任务在实际HUD/卡片/战场接入后核对。仅有基形美术验证，不宣称战斗动画或整局测试已通过。

## 主项目整合结果

v0.3.0已通过art.ts入口接入标题、头像、卡片和战场；新英雄纹理以256×320加载，scale约0.42。网页中WebKit会按CSS显示尺寸报告SVG naturalWidth，因此浏览器验证同时检查图片确已解码与SVG声明的256×320/viewBox，而不要求各浏览器的naturalWidth固定一致。整合验证结果见TEST_REPORT.md。
