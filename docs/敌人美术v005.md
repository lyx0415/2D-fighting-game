# v005 敌方原创形象与连续部位动作

日期：2026-10-30。资产源为`src/game/enemy-art.ts`，静态预览与运行部件共用一套定义。接入入口仍由`src/game/art.ts`统一委托；不要手工修改导出SVG后遗漏源代码。

## 接口与层级

- `enemySvg(kind)`：128×160、透明底、脚底(64,150)、面向右的待机SVG，由同一rig与待机采样合成。
- `enemyRig(kind)`：返回`RigDefinition`。所有`RigPart.svg`均为完整128×160透明图层，pivot使用源画布坐标，parent为解剖层级。运行时需先创建所有关节节点，再按parent挂接；相对位置为子pivot减父pivot，图像位于自身pivot的相反坐标。
- `enemyRigMotion(kind, pose, phase)`：phase为0～1，返回连续角度（度）和位移。idle/move循环，attack/skill0/skill1/hit/dead为单次动作进度；运行切换姿态时由场景进行平滑过渡。

人形有独立双股/双胫、上臂/前臂、头、胸甲、披风和武器。武器挂前臂，盾挂后臂。`body`为全尺寸透明控制层，实际躯干在`chest`；披风和胸甲同时挂body，披风先绘制，避免遮住胸甲，也避免倒地时与躯干脱离。该层包含合法尺寸和透明path，浏览器独立解码通过，不是缺尺寸的空SVG。

多数人形13层、盾卫14层、怨灵10层；狼11层，含四条独立两段腿、躯干、头和尾。共126份运行图层。待机输出不额外烘焙脚底阴影，阴影由战场统一绘制。

## 连续运动约定

步态使用连续三角曲线；抬膝部分采用正半波的平方，身体起伏采用正弦平方，降低落脚点的尖锐跳变。idle和move在phase0/1的位置连续；动作使用分段smoothstep连接蓄力、出手和回收。人形上下臂和股/胫独立转动，肘膝以圆形覆盖衔接，手持物始终跟随对应前臂。表现只影响画面，不修改地面距离、伤害/CD、碰撞或AI速度。

大幅武器动作可以伸出原画布的逻辑范围；运行时加载的是各部件自己的完整纹理，由关节容器组合，不用整个人物画布裁切挥击。静态待机本身保持在128×160内。死亡为一次关节跌倒姿态，由场景保持最终状态，不应循环播放。
